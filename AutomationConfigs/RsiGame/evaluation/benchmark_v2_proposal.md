# Benchmark v2 提案（未启用，未评分）

本提案只规定下一轮有限公开测试设计。原 cycle02 protocol 和 cycle01 独立最终评审保持原样；读取历史评审只为识别缺动态证据、未测几何、缺评分锚点，未复用评分。JSON 是逐项执行定义来源，本文件为同内容的阅读版。

## 冻结与门禁

先独立审核提案，再于新基线和候选采集前冻结实际合法fixture、种子、状态、实体实例、必要字段表、控件别名、题目答案、设备、采集器及阈值SHA。表达式分母必须展开为唯一ID清单与精确N；目前并未完成这一步，不能声称已拥有总体分母或完成benchmark。无法合法到达的用例须在冻结前审核修订；冻结后不得换任务、删失败或缩分母。

所有数值阈值与1–5映射均是待审核工程约定，不是文献结论、合规认证或人体工学标准；没有按当前成绩选门槛。完整率、相对有限图最优和特定机器性能预算分别说明范围。小样本允许跳档，不插值凑分。

必要信息丢失、裁切、明显变形、缩字/整体缩小规避、错误规则/资源消费、画布变化等硬失败保持优先；已有于基线也不豁免，高分不得平均抵消。缺测量不自动满分、不补0或中间分；除8.1/8.2专门证据覆盖项外，未完成预声明必要单元的整项分数为null，保留已测原值与原因。已观察失败、没采集、采集损坏、未知、右删失分别登记。

## 评分档位（工程约定）

- pass_rate：全量已测合格率100%=5，≥95%=4，≥90%=3，≥75%=2，其余1。必要信息/规则硬失败独立判定。
- coverage：相同档位评价明确N的证据执行覆盖；缺证据代表未覆盖，不称UI失败，执行失败仍计执行并另标失败。
- path_ratio：有限UI图最短证书下 r=1为5；≤1.25为4、≤1.5为3、≤2为2、>2为1；每意图最差档决定整项。转换数用(S+1)/(S*+1)。图未闭包/无最优证书则null，参考路径数值照常可报；不称人类或连续空间全局最优。
- latency_ms：36实际输入反馈事件各类及总体P95最差档，≤100/200/400/800ms对应5/4/3/2，>800ms为1；5秒超时右删失，无法定界档位则null。空闲帧间隔不适用。
- visual_fixed：逐图/区域双独立盲评；5清楚一致无观察问题，4可读有轻微问题，3需反复定位/明显密集混杂，2关键层级混淆，1必要内容无法可靠识别。保留分歧、每单元理由和分布，不称客观美感。
- recovery：可恢复任务用path_ratio，合法不可逆任务用预声明提示/状态合同的pass_rate，取低档；缺任一子项null，错误消费不可借此豁免。
- performance：同一冻结设备至少90秒连续实际负载（三次完整8意图，每次至少30秒；不裁尾，报告实际时长），最差次P95≤16.7/25/33.4/50ms对应5/4/3/2，>50为1，并与画布/边界/刷新/异常稳定性档取低者。完整P99、长停顿和Console新增异常同时公开，不能用P95隐藏异常。
