# 原版地图来源数据

`tutorial_opening.json` 是原入门规则第2、3页的起始A、乡村1和2逐格转录。两名代理独立目视核对全部21格，并核验坐标无重叠、三对板块各有三条相接格边。JSON保存原PDF哈希、页码、原图像像素裁区、固定方向、地点规则引用和未完成范围。

这是可复用的来源数据，**尚未接入运行时，也不是完整教学场景**。不得把这三块加入付费探索队列：原书要求开局全部揭示。后续乡村/核心板块与相应原图仍须取得明确来源并逐格校对，不允许猜测或随机替代。

坐标采用现有轴向格方向，屏幕横坐标比例为q+r/2、纵坐标为r。A中心传送门为(0,0)，乡村1中心为(1,-3)，乡村2中心为(3,-2)。所有板块数字与A同向；不开放自由旋转。

`Sea`是原海洋，不能映射成现有`Lake`枚举或由穿湖技能开放。起始A有三海洋格；乡村1有一内陆湖。乡村2西南的绿色图标是丘陵绿晶矿，不能识别成魔法林地。地图正式适配前必须补海洋不可占据、板块与可行走格分离、地点真实消费者及场景证据。

美术仍由原PDF图示定位；当前没有声称已生成透明独立板块纹理。JSON是文本定义，使用普通Git，不使用LFS；查看缓存保留tmp本地，不上传。
