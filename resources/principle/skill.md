在《魔法骑士》中，“**英雄技能标记**”是一套随 Fame 等级成长、为角色提供独特可用动作或常驻被动的可消耗资源。规则书把技能的获取、翻面、使用频次与与专属/通用之分写得很细；但实战中最常出错的只有三个点：① 每升到偶数声望等级才拿技能；② 大部分技能“一回合一次”，少数写明“一轮一次”或“任何回合可用”；③ 使用后要根据标记上的箭头符号翻到灰面，直到下回合或下一轮才重置。下面按规则条目拆解说明。

## 一、获取与存放

* **什么时候得技能？** 英雄声望达到 **偶数等级** (2,4,6…) 时，每升一级获一个技能标记，并摸一张高级行动牌二选一加入牌组；这是与升级选“手牌上限+卡牌”并列的奖励选项。
* **技能来源** 玩家首先从自己角色面板旁的**个人技能堆**中随机抽；若抽空则改从任何其他角色剩余技能堆顶抽（因此后期有机会拿到别人的技能）。
* **摆放方式** 获得后面朝彩色面放在自己面前的“技能区”；游戏外不受指挥槽限制。技能卡背对应角色头像仅作标识。&#x20;

## 二、技能类型与图标

| 图标      | 类型                           | 使用频率                       | 例子 |
| ------- | ---------------------------- | -------------------------- | -- |
| 🔄 翻面箭头 | **一次回合**：本回合任意时点用一次，翻面至灰色    | *Motivation*：摸两牌并得一金魔力     |    |
| ♻️ 灰→彩  | **一次轮次**：只有在自己或所有人轮次结束时才翻回彩色 | *Magic Talent*：夜晚把任意魔力转黑魔力 |    |
| ∞ 常亮    | **常时被动**：不翻面                 | *Desert Lore*：沙漠移动永远-1 MP  |    |

> 若技能文字包含“**在任何玩家回合都可用**”，如激励 Motivation，可打破“仅自己回合”限制 。

## 三、使用与重置流程

1. **满足时点**：只有“Ready 面”技能可发动，检查是否在自己回合及战斗步骤允许的时机。
2. **执行效果**：可能生成魔力、强化数值、抽牌或重排 Source 等；与普通行动牌堆叠计算。
3. **翻面**：带箭头者翻成灰面；**灰面技能在同轮、同回合都不可再用**。
4. **重置时机**：

   * 一次回合技能：玩家 **自己下一个回合开始** 时翻回彩面。
   * 一次轮次技能：**轮次结束时** (所有玩家都 Pass) 统一翻回彩面。

## 四、与其他资源的互动

* **不占手牌**：技能标记不算牌，不受手牌上限、冻结手牌等效果影响。
* **与魔力骰**：若技能产出魔力，应立即取自 Source 或玩家水晶，并遵守昼夜合法色。
* **可被“瘫痪 / 残暴”影响吗？** 否；这些状态仅对单位或英雄攻击/格挡生效，不会禁用技能。

## 五、常见误区快速澄清

1. **Motivation 可在别人回合用吗？** 可以，它的文字特例。
2. **灰面技能能在城镇回合前翻回来吗？** 不能；必须等到规则指定“玩家回合开始”或“轮次结束”刷新。
3. **拿别的英雄技能后头像颜色会影响使用？** 不会；取到手后一视同仁，只按技能图标判时机。
