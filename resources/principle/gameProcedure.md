在《魔法骑士》里，**完整剧本＝若干“天”(Day + Night)，每天包含 1 个或多个“轮次 (Round)”，每轮依次让所有玩家进行若干“回合 (Turn)”**。以下按照“剧本 → 昼夜 → 轮次 → 回合”自上而下，归纳规则书对流程顺序、结束判定及翻面/补牌等细节的全部硬性规定；纯文字描述，可直接作为流程设计文档。

---

## 一、剧本级（Scenario）

### 长度与目标

* 剧本会在说明书或场景书写明长度，如“2 昼 2 夜”“3 昼 2 夜”等。达到指定昼夜数即进入最终结算。([facebook.com][1])
* 若为竞速／合作剧本，还可能附带“击败所有城市”或“消灭沃卡雷”额外胜利条件。([mageknight.net][2])

### 天数推进

1. 开局把昼夜板置于**昼面**。([cdn.1j1ju.com][3])
2. 每结束一个轮次，若还有牌堆未耗尽，则继续同一天；
   当轮次结束且需要翻面，就把昼夜板翻到另一面（昼→夜→昼…）。([cdn.1j1ju.com][3])
3. 当达到剧本指定的昼夜数，游戏立即进入结束结算。

## 二、昼 / 夜（Day / Night）

| 要素               | 昼                                         | 夜                                             |
| ---------------- | ----------------------------------------- | --------------------------------------------- |
| 公共魔力池允许颜色        | 金色可用，黑色禁用；黑色骰重掷直到非黑色。([cdn.1j1ju.com][3]) | 黑色可用，金色禁用；金色骰重掷直到非金色。                         |
| 地形移动花费           | 森林 2，山脉 3                                 | 森林 3，山脉 5；沙漠变 3。([cdn.1j1ju.com][4])          |
| 视觉范围             | 普通                                        | 只能看到相邻六边格；不能探远。([cdn.1j1ju.com][4])           |
| 部分法术拥有“强效”夜间才能启动 | —                                         | 需额外支付黑色魔力。([boardgames.stackexchange.com][5]) |

> **设计提示**：在“轮次准备”时检查昼/夜面，以切换地形表、法术效果与魔力池重掷规则。

## 三、轮次（Round）

### 轮次准备阶段

1. **刷新单位牌列**：弃当前全部单位，补到“玩家数+2”张；核心轮次起银/金交替。
2. **刷新高级行动／法术牌列**：先弃最底→下移→补 1 张置顶。
3. **重置公共魔力池**：骰子重掷并检查黑/金合法性。([cdn.1j1ju.com][3])
4. **玩家选战术卡 (Tactic)**：按声望从低到高依序挑选，决定本轮行动顺序并获得一次性或被动加成。([cdn.1j1ju.com][4])
5. **回合起手摸牌**：每名玩家摸至其手牌上限。([cdn.1j1ju.com][4])

### 轮次进行

* 按战术卡确定的顺序轮流执行“玩家回合”，直至所有玩家连续回合选择 **传递并宣布结束轮次**，或牌堆/手牌耗尽触发强制结束。([boardgames.stackexchange.com][5])

### 轮次结束判定

1. 当有玩家在自己回合开始时 **手牌和牌组皆为空**，必须宣布“结束轮次”。其它玩家各再进行 *最后一个回合*。([boardgames.stackexchange.com][5])
2. 若所有玩家均已宣布结束或放弃回合，则轮次立刻结束，进入“轮次收尾”。

### 轮次收尾

* 所有玩家返还已取的公共魔力骰并重掷。([cdn.1j1ju.com][3])
* 横置部队翻回就绪；回合内获得的临时指挥槽或临时魔力清空。
* 把每名玩家的弃牌堆洗回牌组（若牌组已空）。
* 轮次数 +1；若需要，翻昼夜板并检查剧本是否结束。

---

## 四、玩家回合（Turn）

### 开始步骤

1. 若上一轮末曾“休整”，先弃创伤或治愈后摸牌。
2. 若手牌 + 牌组皆空，则必须宣布结束轮次（见上）。([boardgames.stackexchange.com][5])

### 行动步骤（主阶段，可循环）

玩家可执行以下动作之一，或组合使用卡牌与技能：

| 行动     | 关键成本 / 效果            | 条文                   |
| ------ | -------------------- | -------------------- |
| **移动** | 支付地形移动力；可探索新图板       | ([cdn.1j1ju.com][4]) |
| **交互** | 在所在地点支付影响力/魔力，招募或购物  |                      |
| **战斗** | 依四个子阶段解析：远程→格挡→赋伤→近战 | 官方流程                 |
| **休整** | 弃任意手牌，抓到上限；治愈 1 创伤   | ([facebook.com][1])  |

玩家可随时打出即时/永久技能、横置部队等，只要符号条件满足。

### 结束步骤

1. 宣布是否“继续”或“结束本回合”。
2. 若结束：

   * 可将任意手牌弃置，再摸至上限。
   * 返还公共魔力骰并重掷。
   * 重置本回合横置的部队至 Spent 状态（下回合自动 Ready）。

---

## 五、剧本结束与计分

* 达成场景目标（例如所有城市被攻克）或达到指定天数即结束剧本。([mageknight.net][2])
* 计分通常为总名声 + 城市声望奖励 + 未用战术卡分数 + 单位/法术/高级行动等额外分，最高者获胜；合作模式则看是否成功通关。

---

## 六、设计注意点

1. **数据驱动**：昼/夜状态、轮次数、玩家战术序列建议集中在 `RoundManager` 中统一调度，便于翻面与刷新。
2. **强制结束保护**：代码须在玩家回合开始检查“牌组空且手牌空”，防止遗漏强制结束轮次的规则。
3. **战术顺序重排**：回合结束若后来者宣布结束轮次，其战术卡不会改变已确定的轮次顺序。
4. **UI 提示**：昼夜板翻面、公共魔力池重掷与单位/法术市场刷新应有明显动画提示玩家流逝的时间与资源变化。
