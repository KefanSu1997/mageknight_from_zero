## 1 基础可招募地点

### 1.1 村庄 (Village)

* **进入费**：无。
* **交互**：Influence 2 治疗 1 生命；Influence 6 招募常规单位。
* **负面行为**：洗劫 (= 火攻击 2) → +1 Fame、–1 声望；此回合村庄失效。
* **误区**：洗劫后仍可治疗/招募？**否**，村庄被洗劫即整轮封锁。

### 1.2 修道院 (Monastery)

* **招募**：Influence 值等同单位牌左上角。
* **买高级行动**：Influence 6 可从市场最上方购买并置顶牌堆。
* **烧毁**：击败防御后再 –3 声望；奖励 = 随机神器 1（抽2留1）。

### 1.3 要塞 (Keep)

* **战斗**：Fortified，远程伤害需 Siege 才生效。
* **占领收益**：放自己盾标 → 同地图所有要塞相邻格手牌 +1；可招募常规单位。

### 1.4 魔法塔 (Mage Tower)

* **战斗**：Fortified + Spell 攻击。
* **占领收益**：招募常规单位；学习其上方 Spell（Influence 5 昼 / 免费夜）。

### 1.5 城市 (City)

* **剧本胜负核心**：攻城后留盾标；每张盾 = 招募 +1 Influence 折扣。
* **招募**：可买城市专属精英单位；城市面板还给一次性法术/技能奖励。

## 2 肆虐敌人标记 (Rampaging)

| 颜色     | 出现场景      | 特性           |   |
| ------ | --------- | ------------ | - |
| **棕色** | 初级荒地/森林/山 | 普通兽类、人形怪     |   |
| **灰色** | 高级山地/沙漠   | 升级兽、戈莱姆      |   |
| **紫色** | 核心区域      | 恶魔、龙族，含双抗或毒素 |   |

* **触发**：英雄从邻接六边格进入战斗阶段时必须立即与其战斗。
* **奖励**：击败即得名望；若站在招募地点，可同回合继续招募。
* **注意**：不能用「远程+撤退」方式规避；未击败则强制退回起始格受创伤。

## 3 冒险地点 (Adventure Sites)

| 地形                      | 进入限制                      | 敌人 & 结算       | 奖励             |
| ----------------------- | ------------------------- | ------------- | -------------- |
| **地下城 (Dungeon)**       | 夜视；禁止带部队                  | 抽一棕+一灰敌人同时作战  | 1 咒语 + 1 神器    |
| **坟墓 (Tomb)**           | 夜视；禁止带部队                  | 抽 2 紫敌 连战     | 同上奖励           |
| **水晶洞 (Crystal Cave)**  | 日给对应色水晶 1；夜给相同色魔力 1；结束步触发 | —             | 资源             |
| **古代遗迹 (Ancient Ruin)** | 不限制                       | 地形指示列出若干敌人+奖励 | 奖励可含金币、神器、Fame |

> **算法**：进入冒险地=强制战斗。若失败，退回入口且失去全部奖励。

## 6 常见实现注意

1. **地点图标→交互表**：在引擎中以枚举映射 `SiteType -> InteractionHandler` 统一调度 Influence、战斗、奖励逻辑。
2. **声望即时修正**：每次 `CalculateInfluence` 时调用 `Reputation.Modifier`，避免多次累加。
3. **夜视与禁止部队**：地下冒险地点进入时对 `BattleContext.AllowUnits` 置 `false`；若违规则自动弹窗警告。
4. **Fortified 判定**：要塞、魔法塔、城市、部分紫龙均 `IsFortified=true`，远程阶段检查 `IsSiege` 伤害才生效。
5. **抽神器流程**：实现“draw n+1, keep n”通用工具，古代遗迹与烧修道院共用。
