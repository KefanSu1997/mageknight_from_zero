《魔法骑士》把所有敌人做成双面圆形“**敌人标记 (Enemy Tokens)**”，用颜色、图示与文字能力来一次性编码难度、元素、抗性与奖励。理解这些标记就能推算出任何战斗的流程与数值。下面按“标记颜色→来源→属性→能力→摆放与补充”的顺序，对规则书及常见扩展中出现的**怪物/敌人**做一份系统梳理。

---

## 1  标记颜色与来源一览

| 颜色        | 基本来源                  | 敌人阶级/主题     | 放置例子           |
| --------- | --------------------- | ----------- | -------------- |
| **棕色**    | 肆虐怪、地下城               | 低-中阶兽人、人类强盗 | 地图空地邻格即可翻开战斗   |
| **灰色**    | 要塞、魔法塔、地牢             | 精英守卫、戈莱姆    | “Fortified” 常见 |
| **白色**    | 修道院、城市                | 圣骑士、祭司      | 通常带火抗或治愈       |
| **紫色**    | 核心地块、坟墓、龙穴            | 恶魔、龙族       | 双抗或寒火攻击，最危险    |
| **红/绿/黄** | 扩展敌人堆 (Lost Legion 等) | 元素/机械阵营     | 只在扩展地形出现       |

> 城市防御采用**棕、灰、白、紫四色混合**塞入城市底座，被称作“城市守军”。

## 2  敌人属性条目

每块标记正面印刷以下固定栏位：

| 栏位          | 规则含义                                                                      |
| ----------- | ------------------------------------------------------------------------- |
| **左侧数值与底色** | *Attack* 与 *元素*                                                           |
| （物理/火/冰/寒火） |                                                                           |
| **顶部黑盾数字**  | *Armor* – 击杀所需 netto 伤害                                                   |
| **右侧图标列**   | *Abilities* – Swift / Brutal / Poison / Paralyze / Fortified / Resist X 等 |
| **下方红框**    | 击杀奖励 Fame 值                                                               |

## 3  特殊能力速查

| 能力                                | 效果                         | 关键词    |
| --------------------------------- | -------------------------- | ------ |
| **Swift**                         | 若未被完全格挡，攻击伤害×2             | “迅捷”   |
| **Brutal**                        | 造成双倍伤害，但格挡要求不变             | “残暴”   |
| **Poison**                        | 若受到任何未格挡伤害，则**创伤张数×2**     |        |
| **Paralyze**                      | 若造成伤害，受击方本回合所得所有卡都横置作创伤    | “瘫痪”   |
| **Fortified**                     | 远程/攻城阶段仅*Siege*伤害生效；近战正常   | 要塞守军常见 |
| **Resist Fire / Ice / Cold Fire** | 受到对应元素攻击时伤害×½；寒火需同时火+冰抗才×½ |        |
| **Siege Attack (图标)**             | 在远程阶段就会对玩家发动跟近战同值的攻城攻击     | 城市守军专有 |

## 4  摆放时机与战场分类

### 4.1 肆虐敌人（Rampaging）

* **触发**：探险者走入相邻格立即战斗，无法跳过；可一次把相邻多只一起拉进战斗。
* **奖励**：击败得 Fame，且 Reputation +1（因为清理威胁）。

### 4.2 据点/建筑守军

* **要塞 / 魔法塔 / 修道院 / 地牢 / 坟墓**各自用规则指定色的标记；玩家必须**进入格子**才能挑战。
* 守军被击败后格子翻成占领状态，可招募或购买奖励。

### 4.3 城市守军

* 从城市底座随机抽取对应该城市等级的敌人数；全部击败方能占领。
* 城市守军常带“Siege Attack”“Cold Fire”与双抗，使战斗阶段顺序比普通守军多一轮远程攻城反击。

### 4.4 扩展首领——**沃卡雷 (Volkare)**

Lost Legion 添加塑胶 Boss 迷你：用独立牌堆决定其护卫数与朝向；战斗时按“Volkare scenario sheet”抽敌标记围成环形特殊战斗。

---

## 5  敌人重生与补充（可选变体）

* 官方变体 **Rampage!**：昼/夜结束时为每被击败的肆虐格掷微光骰，若掷出暖色(昼)或冷色(夜)则补出新敌；若金/黑还要附赠一只棕色怪。

## 6  常见规则误区

| 错误理解           | 正确规则                                     | 来源 |
| -------------- | ---------------------------------------- | -- |
| “攻击要塞只算一次战斗”   | 要塞守军 Fortified，玩家若未击败守军，必须退回要塞外且本轮不能再次挑战 |    |
| “寒火元素对火抗敌人全伤”  | 只有**同时火抗+冰抗**才对寒火伤害×½，否则算全伤              |    |
| “Swift=双次攻击”   | 不是两次，而是**一次攻击伤害翻倍**；格挡只需一次满足总值           |    |
| “肆虐怪可先远程射死再移动” | 探索后若怪相邻，先触发战斗→再行动；不能射完再移动                |    |
