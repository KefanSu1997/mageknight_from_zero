# 魔法騎士戰鬥系統摘要

在《魔法騎士》桌游中，每次交戰需依照以下四個子階段順序解析：

1. **遠程‧攻城階段**：可使用帶 `Ranged` 或 `Siege` 關鍵字的攻擊。`Fortified` 敵人僅能被 `Siege` 攻擊。組攻時先將目標護甲求和一次判定。
2. **格擋階段**：為每隻存活敵人分配格擋。若敵人帶有 `Swift`，則需要兩倍格擋值才算完全格擋。元素不匹配時格擋效率只有一半。
3. **賦傷階段**：未被完全格擋的敵人依其攻擊值對英雄或部隊造成傷害。`Brutal` 使未格擋傷害翻倍。傷害換算創傷時，英雄與部隊都按各自護甲取上整。
4. **近戰階段**：可使用剩餘攻擊（近戰或未用的遠程）擊殺剩餘敵人。若所有敵人被擊殺，戰鬥立即結束，否則重複流程進入下一回合。

### 數值與抗性計算

- **有效格擋**：`Block × 元素效率 × (Swift?½:1)`
- **元素效率**：物理=1，元素匹配=1，不匹配=0.5
- **有效攻擊**：`Attack × 元素效率(抗性)`
- **未格擋傷害**：`Enemy.Attack (×2 if Brutal)`
- **英雄創傷**：`ceil(Unblocked / HeroArmor)`
- **部隊創傷**：`ceil(Unblocked / UnitArmor)`

### 進攻能力

- **Swift**：格擋需求×2。
- **Brutal**：未格擋傷害×2。
- **Poison**：英雄受到的創傷同量加入棄牌堆；部隊創傷×2。
- **Paralyze**：英雄棄所有非傷牌；部隊直接被摧毀。
- **Fortified**：只能被 `Siege` 攻擊視為有效。

### FAQ 摘要

1. 部分格擋無效：若格擋值不足，視為完全未格擋，不能減傷。
2. Swift 只影響格擋需求；Brutal 只影響未格擋傷害，兩者可並存。
3. Poison 與 Paralyze 可疊加：先計算創傷數量，再處理副效果。
4. 近戰組攻須將護甲相加，若目標包含抗性則整組按抗性計算。
5. 任何未在遠程階段使用的攻擊值，可於近戰階段當近戰攻擊使用。
