在《魔法骑士》核心与扩展规则中，**“地图地块 (Map Tile)”**、\*\*“特殊地点 (Adventure / Encounter Sites)”**与**“地块翻面”\*\*共同构成了游戏探索-推进节奏的骨架。下面按先后顺序概述：

1. **地块分类、版图结构与摆放顺序**；
2. **地块上的所有图标类型与对应交互**；
3. **探索与地块翻面的完整流程**；
4. **扩展（失落军团、泰兹拉阴影等）附加地形简表**；
5. **常见误区与实现提示**。

## 三、探索与地块翻面流程

1. **触发**

   * 玩家回合内，当其棋子**从已探索格边缘**继续移动到**无人占据的空六边格**时，必须支付额外 2 移动力后执行探索。
2. **抽取地块**

   * 若乡村叠未空，抽 1 张乡村；否则改抽核心地块。
3. **摆放与旋转**

   * 新地块必须使所有道路、河流与海岸线对齐已翻开图板；若多种合法朝向由探索者选择。
4. **即时放置地标**

   * 取地块印刷图标对应的敌人标志、城堡、防御单位，放置于地块指定格。
5. **肆虐怪活动**

   * 若肆虐敌人圆标被摆成**与探索者相邻**，则**立即进入战斗阶段**。其他玩家不受影响。
6. **翻面完成**

   * 新地块已视为“探索”状态；可继续移动进入其中已翻面的任何格。

> **注意**：地块本身**不会再次翻面**；“地块翻面”在规则里仅指“抽黑底→摆彩面”这一探索流程。

## 五、常见误区与实现提示

| 误区         | 正确规则                         | 实现建议                                          |
| ---------- | ---------------------------- | --------------------------------------------- |
| 探索需要停止移动   | 探索后仍可用剩余移动进入地块               | `ExploreTile()` 消耗 2 移动，但不结束行动循环              |
| 地牢可带部队     | 地牢/坟墓**禁止部队**，若带入则其能力失效      | `BattleContext.AllowUnits = site.AllowsUnits` |
| 远程攻击可射杀肆虐怪 | 战斗强制进行，远程阶段可攻击；但**不能**事先远程消灭 | 肆虐怪不当作独立据点                                    |

---

### 实现要点

1. **Tile 类**

   ```csharp
   public record MapTile(int Id, TileType Type, IReadOnlyList<HexInfo> Hexes);
   public enum TileType { Countryside, Core, City, Expansion }
   ```
2. **探索逻辑**

   * 在 `MovementSystem.TryEnter(hex)` 检测 `hex == null` → `MapGenerator.RevealTile(edge)`.
3. **放置实体**

   * 使用脚本 `TileResolver.PlaceSites(tile)` 根据 `hex.Icon` 实例化敌人或建筑。
4. **保存性能**

   * 仅保存地图种子与已翻开顺序；重新加载时按种子重构，使文件体积极小。

---

通过以上梳理，开发者可完整实现地图探索-战斗-资源循环的闭环，同时保证所有**地块、特殊地点、翻面触发**与规则书一致。
