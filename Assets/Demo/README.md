# 魔法骑士可视化测试Demo文档

## 概述

本Demo系统为魔法骑士游戏提供了全面的可视化测试环境，包含三个主要测试场景，用于验证游戏核心功能的正确性和可视化表现。

## 测试场景说明

### 1. 战斗系统测试场景 (CombatDemo)

**测试目的**: 验证5阶段战斗系统的正确性和可视化反馈

**场景功能**:
- **战斗阶段指示器**: 显示当前战斗阶段（远程→阻挡→伤害分配→近战→结束）
- **单位状态面板**: 实时显示攻击者和防御者的血量、攻击、防御属性
- **伤害显示**: 动态伤害数字弹出效果，支持不同元素类型的颜色区分
- **战斗日志**: 详细记录每个阶段的战斗结果
- **阶段控制**: 手动推进战斗阶段，观察每个阶段的计算结果

**测试用例**:
1. **远程阶段测试**: 验证远程攻击的伤害计算
2. **阻挡阶段测试**: 验证防御方阻挡机制的有效性
3. **伤害分配测试**: 验证伤害分配算法的正确性
4. **近战阶段测试**: 验证近战战斗的结算逻辑
5. **结束阶段测试**: 验证战后状态的更新

**预期现象**:
- 每个战斗阶段都有明显的视觉区分
- 数值变化有平滑的动画效果
- 战斗结果与预期计算完全一致
- 日志清晰记录每个阶段的关键信息

### 2. 地图系统测试场景 (MapDemo)

**测试目的**: 验证地图探索、地块放置和移动机制

**场景功能**:
- **六边形地图网格**: 可视化显示地图布局，支持点击交互
- **地块浏览器**: 显示可用地块的详细信息
- **玩家棋子**: 可交互的移动单位，支持拖拽操作
- **移动路径**: 显示可能的移动路线和消耗
- **地形信息**: 显示不同地形的类型、移动消耗和特殊效果
- **地块旋转**: 支持地块的旋转操作，观察不同方向的效果

**测试用例**:
1. **地块抽取测试**: 验证地块从牌库到地图的正确抽取
2. **地块旋转测试**: 验证旋转功能对地块效果的影响
3. **移动消耗测试**: 验证不同地形的移动成本计算
4. **边界检测测试**: 验证地图边界的限制机制
5. **探索流程测试**: 验证完整的探索流程

**预期现象**:
- 地块可以正确地从牌库抽取并放置到地图上
- 地块旋转操作直观且效果正确
- 移动消耗计算准确，路径显示清晰
- 探索流程符合游戏规则

### 3. 卡牌效果测试场景 (CardEffectsDemo)

**测试目的**: 验证100+卡牌效果的正确触发和可视化表现

**场景功能**:
- **卡牌展示墙**: 分类显示所有可用卡牌效果
- **效果触发器**: 手动触发特定效果，观察结果
- **状态监控**: 实时显示玩家状态的变化
- **效果日志**: 记录每个效果的触发历史和结果
- **分类筛选**: 按效果类型筛选显示卡牌

**效果分类**:
- **攻击类**: 火球术、闪电、冰箭等直接伤害效果
- **防御类**: 治疗、护盾、减伤等保护效果
- **资源类**: 魔力获取、卡牌抽取、资源增加效果
- **特殊类**: 传送、召唤、变形等特殊机制效果
- **控制类**: 冰冻、恐惧、沉默等控制效果

**测试方法**:
1. 选择要测试的效果类型
2. 点击具体的效果卡牌
3. 触发效果并观察结果
4. 检查玩家状态的变化
5. 验证效果是否符合预期

**预期现象**:
- 每个效果都有独特的视觉表现
- 效果触发后游戏状态正确更新
- 可以重复测试同一效果
- 效果分类清晰，便于查找

## 使用指南

### 基本操作

1. **启动Demo**: 在Unity编辑器中打开任意测试场景
2. **场景切换**: 使用DemoTestManager的UI界面切换不同测试场景
3. **重置测试**: 每个场景都有重置按钮，可以恢复到初始状态
4. **调试模式**: 开启调试面板查看详细日志和性能信息

### 测试流程

#### 战斗系统测试
1. 打开CombatDemo场景
2. 观察初始的单位状态
3. 点击"下一阶段"按钮推进战斗
4. 观察每个阶段的变化和结果
5. 使用"重置战斗"按钮重新开始

#### 地图系统测试
1. 打开MapDemo场景
2. 点击地图上的六边形选择探索目标
3. 调整地块旋转角度
4. 点击"探索"按钮执行探索
5. 观察地块放置和玩家移动

#### 卡牌效果测试
1. 打开CardEffectsDemo场景
2. 从左侧选择效果类型
3. 点击具体的卡牌效果
4. 点击"触发效果"按钮
5. 观察效果触发和状态变化

### 调试功能

#### 调试面板
- **实时日志**: 显示系统运行状态和错误信息
- **性能监控**: 显示FPS和内存使用情况
- **快速重置**: 一键重置当前测试场景
- **场景切换**: 快速切换到其他测试场景

#### 日志系统
- **信息日志**: 记录正常操作流程
- **警告日志**: 记录可能的异常情况
- **错误日志**: 记录系统错误和异常

## 技术说明

### 架构设计
- **MVC模式**: 分离测试逻辑和UI表现
- **事件系统**: 使用UnityEvent实现松耦合
- **数据绑定**: 实时更新UI显示
- **对象池**: 重复使用UI元素提高性能

### 性能优化
- **延迟加载**: 按需加载测试内容
- **缓存机制**: 缓存频繁访问的数据
- **对象池**: 减少GC压力
- **异步操作**: 避免阻塞主线程

### 兼容性
- **Unity版本**: 2023.x及以上
- **平台支持**: Windows, macOS, Linux
- **渲染管线**: 支持URP和内置渲染管线

## 故障排除

### 常见问题

**问题**: 场景加载失败
**解决**: 检查场景是否在Build Settings中正确配置

**问题**: UI元素不显示
**解决**: 检查Canvas设置和UI层级

**问题**: 效果触发无反应
**解决**: 检查控制台日志，查看是否有错误信息

**问题**: 性能下降
**解决**: 检查是否有内存泄漏，使用Profiler分析性能瓶颈

### 调试技巧

1. 使用Unity Profiler监控性能
2. 查看控制台日志获取错误信息
3. 使用断点调试复杂逻辑
4. 检查场景中的对象引用是否正确
