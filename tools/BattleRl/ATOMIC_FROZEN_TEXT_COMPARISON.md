# 冻结 mmBERT 原子战斗对照

新入口 `train_sb3_atomic_text.py` 保持原子单场动作、原 DLL、4000/1000 组成划分、完整局采样和上游 SB3-Contrib RecurrentPPO。32 环境每次收齐128有效完整局，每局最多128复合动作，γ=λ=1，reward固定乘0.01。普通败局保留，接口/审计失败仅隔离坏局并补采；固定验证保留1000分母。

冻结本地 `jhu-clsp/mmBERT-small` revision `abc32620dd4f6ab06f5fbe905dc25f310618e09f`。沿用先前已验证的全部token分块、mask平均及L2规范化 reader。291个公开实体规则描述、427个操作类型/模式共718文本实际编码，模型完整SHA前后不变且0梯度。静态编码在现有CPU文本环境完成一次后卸载；正式PPO前向、反向、Adam在RTX4060 CUDA执行，运行时无需在线调用编码器。不是Jev/Laya/RLCD训练配方复现，也未实现成功概率校准头。

保留完整原数值状态和已有字符特征。原公共6314坐标白名单决定可见实体，对其384维mmBERT规则表示取均值，追加到状态；阶段、数量、费用、目标/材料槽等继续由原数值特征表达。候选表示由操作类型/模式、原卡/技能规则及显式材料规则的预训练向量均值构成，并追加到原动作描述。完整复合操作仍由原联合动作头处理，不截断合法支持集。该设计测试静态预训练规则表示的增益，不声称编码器已推理完整数值局势或多步战斗。

配对 `text` 使用真实向量，`zero` 将新增384列置零；形状、可训练参数、随机初始化种子、超参数及预算相同。原采样课程算法相同，但其根据各自历史胜率调整分布，所以训练后访问轨迹不承诺逐局相同。两臂各fresh100更新，顺序运行，0/20/40/60/80/100同1000任务与逐任务actor RNG独立验证。单个训练种子不足以证明稳定统计增益；原299模型为历史参考。

4个真实完整局53动作的CUDA门禁：两臂初始可训练参数SHA相同，上游PPO真实更新、23 Adam状态有限，保存重载logprob差0。状态文本输入98303个权重、候选文本输入12288个权重真实改变；该门禁只证明集成，不证明获胜或泛化。

所有rollout、原子支持集、失败和微轨迹保存。中间行为模型每50更新保存，另保初始、当前可恢复checkpoint与最终模型。固定编码向量和原文SHA随manifest绑定；每步的实际追加向量在rollout内，不能用旧全局ID解释原子支持ID。
