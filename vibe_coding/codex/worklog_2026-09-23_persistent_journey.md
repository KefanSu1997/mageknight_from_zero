# 同一玩家的连续战斗会话

## 已完成

新增 `Assets/Logic/Runtime/Battles/PveJourneySession.cs`，由同一个 `GameEngine`、实际玩家、全局魔力源与地图驱动准备新轮、原战术、开始回合、开始战斗、结束回合、轮末声明与结束轮次。会话本身不调用 `CreatePlayer` 或复制牌库；战斗继续共用已有 `PveBattleSession/TurnMachine/CardPlayActions`。

- 每回合的新 `ActionContext` 绑定真实源骰和地图；战斗与战后恢复沿用该同一上下文，结束回合调用正式清理和补牌。
- 活动战斗不能被新战斗替换，不能提前结束回合；行动已用后不能再开启另一次普通行动。非法敌人选择不消费行动。
- 敌人按物理引用跟踪：已击败原标记不能再次发奖，同牌面的另一实体可以；未击败原标记能在后续回合继续面对。地图地点/守军结算仍须后续世界层接入，不把此接口当作完整地图。
- 战果保留可读。`PveBattleSession` 增加可选回合有效性条件并在18个修改入口检查，旧回合的按钮不能在回合结束后、甚至下回合开始后继续付费、治疗或改状态。原独立快照入口兼容。
- 没有自动重整、治疗、补晶体或重建出战快照；每轮重整与创伤保留由正式服务处理。
