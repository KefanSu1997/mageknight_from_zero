# 启迪头环普通借用：只读审计与最小实施方案

2026-09-29。仅阅读源码及既有测试；未修改生产代码，未运行 CLI 或 Unity。以下为静态发现，不冒充已验证故障。

## 结论与原文边界

`resources/text_json/items.json` items_022 普通原文：使用公共供应中的非互动技能；每回合均能使用、不会翻面的技能效果使用两次。焚毁是永久取得，两者不能共享“取得技能”的副作用。

目前 `HeadbandEffect` 只支持直接 Effect 和一个整数选项。新增动态技能多数正式入口在 Actions 中，Effect 明确拒绝。`PveJourneySession.SpecialArtifacts.cs` 仅开放静态 `BattleSkillChoice.For`，参数不足以表达实际伤牌、贡献、横置牌、付款或移动目标。扩展 UI 参数还不够，必须区分自有技能使用与头环授权借用。

现有基本证据（`HeadbandBasicStateTests`、`PveSpecialArtifactEntryTests` 和已完成的场景索引）证明黑暗道路/类似固定输出、暗火魔法及焚毁取得，不能推论所有非互动技能可借。

## 比入口缺失更危险的双用语义

1. `HeadbandEffect.Execute` 的循环把同一选项和同一 Context 输入执行两次，未预检第二次。`CardPlayActions.PlayArtifact` 在 Effect 成功后才移走头环；因此第二次异常可能留下第一次资源变化而头环还在手里。
2. 战斗狂乱强化第一次加入 `player.FlippedSkills`，第二次因已翻面拒绝。萨满仪式是 ManualFlip，当前直接被 Headband 频率拒绝。原文“不会翻面”的判断不能仅依赖 Frequency=OncePerTurn；特殊翻面借用应先核原版详细解释，不能猜成攻击8或篡改个人翻面状态。
3. 痛苦之力双次 `SidewaysWoundValue=2` 与灵魂向导双次 `SoulGuideBlockPending=true` 都覆盖一次许可，实际只消费一次。两次使用不能简化为数值翻倍，也不能把两张伤牌合成一张值4。
4. 任意 `SkillsUsedThisTurn/Round`、FlippedSkills 的增删都应区分自有与借用。禁止把公共技能暂塞 `player.Skills`、暂删个人已用标记再恢复；那会触发持有者被动/事件和来源身份错误。

## 最小充分实施方式

不另写卡牌规则。引入窄的头环借用状态/授权，复用现有 Actions 的目标、费用和实际消费代码。

- 借用状态绑定真实玩家、物理头环、实际公共技能引用、当前 ActionContext、剩余次数、当前待选输入。创建前校验真实手牌与公共供应引用、非互动及当前合法技能分支。
- 正式 Actions 保留普通公开入口的自有校验；拆出内部“已合法授权”的执行核心，或使用不可由普通调用者伪造的授权对象。核心统一处理真实材料/阶段/资源；成功后由调用路径分别记自有次数或借用次数。不要暴露一个无来源的 `ignoreOwnership=true` 开关。
- 先落实一次输入的完整校验，再提交首次出牌与消费。首次成功后物理头环进入已打出区、公共技能仍在供应。第二次从当前真实状态重新选择；失败保留第一次成功结果与剩余次数，不能退回头环重新赚第一笔。
- 复用项目 `RepeatedEffectResolution` 的未完成选择保护及现有动态续选 UI 思路，避免再造整套框架。借用未完时应阻止正式回合/阶段跳过；是否允许少做一次按原规则“尽可能执行”及合法输入处理核定，不直接规定必须拥有两份材料才能打出。
- 普通自身使用标记、公共技能位置不变；借用状态完成后清理。战斗来源记录保留原技能/原牌/实体，长期奖励不能依赖临时把技能设为拥有。
- UI 在原神器卡面面板展开实际输入，并显示第1/2次；每次枚举最新实际手牌、贡献、目标，禁用已消费实例。允许独立选项，不强迫两次相同颜色或目标。

## 建议优先落地的一组

**第一组：百步穿杨 + 漫不经心/通用力量（随后魔法抗拒）**。这组均有清晰真实输入和直接消费者，不依赖持久翻面或历史击败捕获，可先建立窄授权与逐次动态选择机制。无需先做混乱、傀儡或决斗的跨阶段多目标状态。

必要后台范围（仅新增/直接受影响）：

1. 从真实公共供应借未持有技能，头环只进入已打出一次；供应引用和个人 Skills、个人次数不变；同 ID 假实例/互动技能拒绝且守恒。
2. 百步穿杨两次选择真实原牌攻击，保留元素、来源与奖励；实际原敌防御消费值正确；已消费/单位来源贡献拒绝不扣第二次额度。
3. 横置两张真实手牌逐次出牌；同一实例第二次拒绝但第一次结果保留；通用力量两次实际付款、颜色可独立选，材料不足时不能重复第一笔收益。
4. 魔法抗拒真实源骰使用历史及放弃承诺继续适用，借用不能绕过费用或源限制。
5. 借用未完的正式阶段/回合保护、完成清理；正常自有技能同一组既有用例定向回归（不用全70/全卡库）。固定头环正常/焚毁三个旧用例作直接回归即可。

集中场景：一次合法连续旅程，通过真实升级公共供应形成被借技能（不能把公共技能改成已拥有）；两次实际贡献或两张手牌→真实击杀/移动→正式回合末头环弃牌；保留必要截点。不要为了几种技能把所有英雄和互斥构筑硬塞一局，可分合法组。

## 基本必需与延后范围

- 非互动技能的普通合法输入、一次/两次效果及费用、实际来源/归属与目标，是头环正常效果覆盖问题；不能一概归为“复制边缘情况”。可按上述组逐批补，状态仍记具体缺口。
- 原版特殊借用解释不足的混乱盾标、翻面型、忠诚持续取得效果、傀儡历史保留，需要定向核原规则后做；仅凭本地简卡文不能宣称实现语义已确定。
- 暂不做多层复制/宝盒再借头环/多层付款技能联动交叉穷举、所有70技能×全部目标全排列。已支持普通固定输出保留有效历史证据，不重跑全库。
