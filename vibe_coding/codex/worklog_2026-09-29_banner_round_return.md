# 原旌旗轮末保留与取回

## 问题与实现

六种原附旗已有正式 `BannerActions.ChooseRoundReturn` 和 `GameEngine.EndRound` 结算，但玩家界面没有选择入口。此批复用原规则，在所有玩家最后回合结束、轮末清理之前提供保留/取回选择。

- `Game.CanChooseRoundBannerReturns` 区分实际轮末窗口和轮末结算后旧倒计时标记，避免在新轮准备期间再改旧轮选择。
- `PveJourneySession.Banners` 只列本局指定玩家实际自有、未销毁、实际附旗部队；选择操作保留引用和所有权校验，复用原BannerActions。
- 轮末UI默认保留，逐单位切换取回或取消。显示所有者、部队、原旗图片与名字；指挥旗明确警示所附单位会被移除。每页四项支持多玩家，不靠切换当前玩家修改归属。
- 点击选择不提前移动卡牌或单位；正式结束本轮统一释放、洗牌，新轮按已有规则补牌/重整。普通旗取回保留原单位，指挥旗取回复用原Release移除单位。
