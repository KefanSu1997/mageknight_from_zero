# 原英雄回合末升级与真实奖励补牌

## 修改与规则

对照本地原规则书第11页的回合结束/升级步骤（已有图 `tmp/pdfs/round_book_page_11.png`），本批将升级放到实际回合清理之后、弃剩余非伤牌和补牌之前。连续旅程锁定已结算等级，战斗所得名望先累计，不能提前增加本回合的护甲、指挥槽或手牌上限。旧独立演练快照仍按其初始名望计算等级。

- `GameEngine` 拆出 BeginEndCurrentTurn/CompleteEndCurrentTurn；前者执行原清理，后者执行原补牌与计时。等待升级时仍占用当前回合，阻止开始新回合、战斗、普通出牌和结束轮次。原 EndCurrentTurn 调用者仍一次完成两步。
- `HeroProgression` 复用实际英雄的10个原技能定义、随机技能堆与正式高级行动供应。偶数等级翻两枚自己的技能：选一枚和任意高级行动，另一枚进公共区；选他人的公共技能则必须取最底高级行动，两枚自己技能都进公共区。全部选择先校验，原供应立即补空位，取得的真实牌先置顶再补牌。
- 奇数等级应用原护甲/指挥槽；连续跨级逐项结算，最后按新手牌上限补牌。不清空旧技能使用记录，不重建玩家或牌库。
- 旅程现在共享 Game.Globals 的行动、法术、神器与技能供应；原手牌回合末弃牌标记延后到奖励之后消费。新技能和新牌自然沿用后续回合。
- Unity 新增升级选择页，展示原技能参考页/印刷规则及三张真实高级行动原图。学得技能在后续战斗显示，原菜单生成器绑定14张既有参考页。技能参考页并非新画的技能图，亦不代表每种技能的使用入口已完整。
- 随机原起手场景通过 `Hand/#0` 找到真实可见按钮，仍走同一个 Button 的点击回调，不固定有利牌序或注入名望。自动化仅新增按可见子项索引定位按钮的支持。
