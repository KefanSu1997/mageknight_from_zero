# 原卡资源转换与宁静时光入口

本批接入灵动 advanced_card_006、外交 advanced_card_018、宁静时光 advanced_card_035。保留已有正式效果与原卡素材，只增加 PVE 模式和玩家实际消费入口。

- 灵动：基础/强化的移动池共用正式回合状态；攻击阶段按 1 移动换 1 近攻、强化按 2 移动换 1 远程。可以逐点或支付当前全部可转换资源，再在实际战场选目标结算。
- 外交：基础普通格挡、强化寒冰/火焰明确选择；正式影响力按 1:1 转成对应元素格挡，再由现有格挡分配消费。阶段、余额、未完成重复效果及已结束回合均经过入口验证。
- 宁静时光：出牌先得到影响力与可选能力，不强迫立即消费；战斗外按 2 影响换 1 治疗，强化按部队等级×2影响重整。复用 PeacefulMomentActions 和 CardUnitActions，转换实际占用行动；重整保留创伤。与原无情威压重整入口分开指定许可。
- UI 使用原图、原文和真实余额。战斗侧栏按需出现资源转换入口；宁静时光位于手牌的“休息 / 技能 / 卡牌能力”。不新增调试资源加减器。
