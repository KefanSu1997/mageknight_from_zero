# 公正之剑、星辰之弓：原卡、真实卡区与战斗联验

## 来源和修改

复用 items_008 / items_016 的既有 SO、中文及英文原卡面、JusticeSwordEffect / StarBowEffect。没有新造武器或降低预期。

基础弃牌先检查每张真实实例、重复选择和创伤，再一次性移入弃牌堆，合计形成一笔攻击。CardPlayActions 的原武器入口消费真实手牌；基础进入已打出区并在回合末进弃牌，焚毁进入永久移除记录，不能重复使用或误移除同 ID 的另一实例。

剑的额外名望持续本回合，弓仅持续当前战斗阶段；远程、格挡/近战与 TurnMachine 接入奖励和阶段切换，结束战斗及结束回合分别清理相应奖励。保留其他卡已有奖励字段，避免把不同期限混用。

焚毁剑仅在攻击阶段翻倍物理攻击；只忽略物理抗性，不忽略火/冰抗性。焚毁弓按每笔 AttackProfile 选择：远程翻倍或原值转攻城，攻城可保持原值或翻倍变远程。颜色保留，城防按转换后的类型判断，非法选择/目标不消耗攻击。默认新远程贡献翻倍、攻城不变，可以在结算前逐笔改变。
