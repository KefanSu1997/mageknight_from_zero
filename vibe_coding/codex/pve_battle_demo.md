# 原版 PVE 战斗演练

入口：Unity 菜单 `Tools > Mage Knight > Battle > Open Demo`，再进入 Play。场景为 `Assets/Scenes/Part1/Part1_PveBattle.unity`。

操作：点选手牌，选择基础或强化效果，确认出牌。可以连续出牌累积本阶段资源，再点选一个或多个敌人并结算攻击；格挡阶段选择一个敌人的一次攻击。右侧可展开本阶段规则，下一阶段按钮依次推进远程/攻城、格挡、英雄承伤和近战。最后点击结束战斗，只有全部敌人被击败才显示胜利。中途放弃剩余攻击也能结束，但不算获胜。

顶部“出战配置”可分别切换手牌和敌群，然后开始新的演练。它们是独立的 `BattleLoadout` / `BattleEncounter` 资产，位于 `Assets/GameData/BattleDemo`。Inspector中的场景组件可添加更多配置。默认两套可复现出战手牌快照，不冒充英雄标准初始牌库。

- 稳守反击 / 遗迹哨卫：决心蓝色强化格挡5，挡住兽人骷髅战士攻击4；狂怒红色强化攻击4击败护甲3，名望+2，无创伤。
- 先发制人 / 兽人战团：敏捷白色强化远程3与利斧投掷蓝色强化远程3合并，经过兽人物理抗性后有效3，击败护甲3的毒素兽人；敌人名望4加利斧击杀奖励1，共获得5。另一颗蓝晶强化决心得格挡5，但狼骑兵攻击3且迅捷，需格挡6，格挡5不能减伤。护甲2英雄承受完整攻击后加入2张真实创伤。狂怒红色强化攻击4击败护甲4狼骑兵，再获名望3，合计8。

正式规则由 `PveBattleSession` 调度现有 `CardPlayActions`、`TurnMachine`、`CombatPowerPool` 和 `BattleResolver`。它接收真实玩家及敌人，不维护第二套规则数值。场景敌人来自与后台同源的原怪物JSON，原卡引用已有SO和原卡面；背景及英雄沿用已有独立素材。

当前交互范围：决心、狂怒、敏捷、利斧投掷的战斗效果及普通原卡横置；另有实际已招募部队的激活、耗竭、按敌人攻击分配承伤与战斗结算。底部“部队”切换原卡面，点部队使用本阶段原能力；分配伤害阶段点敌人、点部队、加入/取消承伤，最后确认。出战配置新增“魔像协防”与“烈焰援军”，分别适配“双重哨戒”和“毒素兽人”，仍可独立组合。

部队首批5后台用例、两场47次点击/129检查通过，证据见`worklog_2026-09-18_battle_elements.md`。这仅证明魔像与枪手及其对应流程，不代表30种有效部队完整支持。其他卡的专项材料/目标选择、神器、英雄技能仍需继续接入；演练没有完整招募流程、探索和回合补牌，战斗结束后保留真实已打出区供上层回合系统接管。战斗场景不是121张卡所有组合的UI验收替代。
