# 大师四能力接入正式PVE操作（待验证）

## 来源与实现

继规则审计后阅读本地`rulebook_chinese_quick_start.PDF`第9页，确认部队能力图标表示使用时机；原`army_en_005.png`蓝/红为格挡，绿/白为远程类。按格挡阶段蓝/红、远程或近战阶段绿/白接入。原Lost Legion扩展第5页的首次耗竭/继续付费、每项一次、未受伤和交涉招募约束沿用上轮来源。

- 原JSON标记`interaction_recruit_only`；解析四个有色能力，原多能力被动不生成第五个按钮。loader27，尚缺魔宠/斥候/奇袭队。
- 正式`DelphanaMastersActions`通过`CardUnitActions.Use`进入，共用真实Mana支付、敌人引用、有效抗性和减甲消费者。逐次选择原能力与目标，失败保留先前结果，首次就绪后耗竭；本场已激活未受伤的大师可继续使用本回合尚未使用的能力。战末取消继续权限与红色待结算目标，回合末清理已用能力；不临时重整部队。
- 蓝色真实停攻；绿色共用最低1护甲计算；白色清除本场地点/敌人城防与抗性，不能移除奥术免疫。红色按原敌引用登记条件，在`BattleResolver`真实防御结算后，全部攻击成功格挡才消灭；取消/停攻不算格挡。攻击已降至0按原规则自动格挡，使用正式击杀/名望/战场记账，不另造奖励路径。
- `PveBattleSession`接目标和费用入口；原部队面板按阶段显示能力，已用项标注并禁用，同时保留实际耗竭状态。`UnitState.CanActivate`普通语义保持不变，额外显示大师是否可继续。
- 免费招募和供应借能力入口在付款/移出供应前拒绝此类受限部队。普通正式城市交涉仍可招募；其他战斗奖励取得入口尚需随全量初版核查，不能仅凭这两处防线宣称全部取得路径完成。
