# 连续旅程：原部队供应、村庄交涉与影响力消费者

## 原规则与实现

查看本地原规则第4页和入门第9页（`tmp/pdfs/round_book_page_4.png`、`reputation-guide-09.png`）：招募必须来自实际供应及对应地点图标，成功才支付费用和指挥槽；招走不补位，下一轮将整列剩余部队归对应牌堆底，再翻玩家数+2。核心板块揭示后精锐/常规交替。村庄每3影响力购买1治疗点，治疗部队仍按等级消耗；交涉声誉修正整次计一次，负七不可交涉。

新增共用 `UnitSupply`，常规/精锐实际牌堆及供应按引用保留。正式 `GameEngine.PrepareNewRound` 统一轮换，旅程每回合 `Context.UnitOffer` 绑定同一真实列表；招募复用 `CardUnitActions.TryRecruit` 和 `RecruitmentService`，没有接旧教学代码中的自制村庄守卫/游侠或未扣费治疗。已有后台服务负责地点、声誉、费用、指挥槽、原招募奖励。修正 BeginInteraction 在声誉X时先拒绝。

`PveJourneySession` 接入当前已揭示村庄的实际交涉、原供应选兵、实际影响力支付、购买治疗点、结束交涉、横置影响力和自有部队解散。用原卡获得的影响力重整许可走 `CardUnitActions.TryReady`，不顺带治疗。影响力治疗获得正式治疗池，再由原治疗消费者处理真实英雄/部队伤牌和额外效果。

新增5种原卡操作分支：高贵气质、无情威压、胁迫、英雄事迹、求援；复用原卡面、数据及正式效果，不另写数字。高贵气质在交涉内才获名望/声誉；英雄事迹按成功招募发奖；求援按实际手牌和部队伤数。无情威压基础减费可明确不使用，只有实际使用并招募成功才降低声誉；强化按部队等级付2倍影响力重整。折扣消费不再清掉其他来源的招募减免。

Unity 通过“村庄交涉 / 部队供应”查看原图和地点图标、选择部队、付款招募；手牌页显示影响力并提供横置/许可重整。新招部队的战斗卡图从完整原单位目录查找，不再局限开场快照单位，否则新招兵会因查不到图而报错。

PVE独立旅程配置复用旧地形与独立村庄美术，在(0,1)配置村庄；没有改旧探索教学配置。仍是明确标注的自定地图布局，不冒充原版七格板块探索。当前Demo供应每种原定义各一实体，减去开场已带部队；自定构筑使用配置目录顺序，标准英雄开局会随机混洗供应。完整桌游各部队印刷副本数量、修道院额外高级行动、各类地点与核心地图消费者还需后续接入，不能把当前供应目录当全套实体数量已完成。
