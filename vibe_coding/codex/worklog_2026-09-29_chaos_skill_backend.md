# 混乱大师取得与正式回合后台

依据 `tmp/hero_recruit_flip_entries_20260929.md` 的本地原英文技能图审计，未联网、不操作Unity、不推送。

## 接入
- 新 `HeroSkillAcquisition.Acquire(player, skill, random=null)` 保存真实技能引用。混乱取得时用正式ManaDie.RollUnrestricted六面掷骰初始化一次；同一已持有实体幂等，另一个同SourceId实体拒绝。读档已有颜色不重掷。升级取得、头环焚毁、旧修道院取得分支改走共享钩子；原修道院选择/供应旧缺口未冒充修好。
- 新 `ChaosSkillRules` 先预览顺时针蓝→绿→黑→白→红→金，再校验阶段及金色明确选项，然后改变颜色并给奖励。黑为真实ColdFire/Ranged贡献1。Options返回当前合法动态选项，不修改色。
- 蓝仅格挡阶段，黑远程/近战，红近战（已有全攻城许可例外），绿战外可移动时，白战外非休息。失败不旋转、不给资源、不用次数。次数由正式SkillActions统一处理。
- 正式EndTurn在技能使用记录清理前、仅本人活动回合中建立未用空转待选；显式 `ResolveUnusedRotation(player, rotate)` 在下回合前转一次或保持，不给奖励、不占下回合次数。StartTurn若未决则先拒绝，颜色跨回合/轮保留。主代理接入这些回合及GameEngine原子预检钩子、构筑与UI。
- 头环普通借用混乱需要独立盾标记规则，当前明确拒绝；焚毁取得支持，不冒充借用完成。
