# 骑士精神与利斧投掷：奖励归属实际攻击

## 原规则与修改

目视核对原英文卡面 `advanced_card_en_034.png` 与 `basic_card_en_011.png`。骑士精神选择普通攻击3/6，或攻击2/4并对本次攻击每个击杀获得声誉1（强化再加名望1）；强化利斧投掷远程攻击3，在本次攻击至少击败一敌时额外名望1，多个敌人仍只加1，远程贡献用于近战也适用。

旧实现把奖励写入全局 Pending 字段，第二张同卡覆盖第一张奖励；利斧失败或结束战斗后残留奖励，且用于近战不发奖。现在把每敌名望/声誉、至少一敌名望三项附在正式 AttackProfile 上，BattleResolver 与 RangePhaseResolver 只结算实际使用贡献的奖励。消费攻击与结束战斗自动同时清理其奖励；保留英雄决斗等其他 Pending 使用者，避免无关重构。两张卡增加印刷选项验证，付款及实际出牌之前拒绝无效选项。

场景夹具增加多目标选择，复用正式 TurnMachine；可直接进入合法近战测试起点（无攻击敌人完成前序阶段）。显示实际/预期名望、声誉，并记录实际白色魔力。真实出牌使用原定义与真实手牌实例，结束回合验证已打出转弃牌。
