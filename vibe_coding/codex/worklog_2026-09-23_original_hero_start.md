# 七位原英雄标准开局与回合末实际弃牌

## 修改思路与功能

此前连续模式从1—7张演练手牌和预置晶体/部队创建玩家。本批新增独立“选择原版英雄 · 标准16张牌开局”入口；旧演练入口用于定向配置，不作为原版开局。新增共享 `OriginalHeroes` 七英雄定义，各16张基础行动，按对应英雄两张专属牌替换，保存不可变定义及自身技能池身份；创建16个独立牌实例后正常洗混，交给现有 GameEngine.PrepareNewRound 抽5张。生产入口不固定随机种子，后台可注入 Random 重放。

新玩家起始等级1、护甲2、指挥槽1、名望/声誉0、魔晶/临时魔力0、部队0、已学技能0。PlayerState 增加 HeroId，战斗状态和画面用实际玩家身份；不继承上次演练英雄名字、晶体和已招募部队。选择面板绑定既有原专属卡图、牌名及完整构成预览，不生成新卡。原图暂用于英雄识别，没有冒充独立英雄肖像资产。

为使实际16张牌库能正常轮转，在战斗外手牌面板加入“回合末弃掉所选牌”。选择只做标记，真正EndTurn时先验证整组选项，再按引用弃实际非创伤手牌，然后走现有回合结算/补牌。可以取消选择；选择后用于出牌的牌自动退出弃牌选择。拒绝伤牌、手牌外实体、重复同一实例及战斗中/回合后操作；同ID两张不同实体仍可分别弃掉。保留的牌不替换成新卡。

## 原来源

核对本地原入门规则书第4/5页及中英文原卡图。规则明确16张洗牌抽5，起始一个指挥标记；英雄卡下方晶体是虚拟玩家用，不免费发给正常玩家。七英雄映射、来源链接以及民间扩展疑点见 `original_hero_start_source_audit_2026-09-23.md`。

重要口径修正：七英雄标准牌集合26种，不包含旧合图中的 basic_card_011/025。此前121张有限验收是仓库卡库范围，不能继续笼统称全为官方原版。旧测试与历史效果保留，不改写通过证据；两张不进入标准英雄开局。既有39种操作分支中含这两种，故只能表述为“37种七英雄原版/法术分支+2种历史扩展分支”，均不等于整卡全部效果完成。
