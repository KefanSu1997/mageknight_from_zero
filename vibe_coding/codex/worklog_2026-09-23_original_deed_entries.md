# 原卡目录、原法术费用与连续操作入口

## 修改思路与实际功能

复用已有原卡定义、原图和正式 ActionSystem/CardEffects，把战斗手牌从少量固定绑定扩展为统一目录。新增 `BattleDeedDefinition` 只关联 CardSO 与同 Id 原图，不定义替代效果；选择器按基础行动、高级行动、法术、神器分页，可配置1至7张自定起点手牌。该起点用于演练构筑，明确不是正式英雄16张起始牌库。只有初始化时创建玩家，后续两战和回合保持同一牌实例、费用和牌区。

目录为121张有效原卡（28基础、44高级、24法术、25神器）。首次场景发现旧资源的三个空白槽 `advanced_card_044..046` 与牌背 `advanced_card_047` 被纳入，已依据既有 `tools/audit_card_sources.py` 的原图审计排除，未删除历史失败或扩大有效牌数。

新增一批原卡的战斗选择入口，包括晶体/魔力选色、原元素攻挡与远程/攻城、影响力，以及原火焰魔球、风雪交加、烈焰之墙和魔力箭矢的上下半选择。现在22种行动/法术 Id 有战斗分支，部分仍不完整；不为未知卡默认执行选项0。原神器目录25张，原10张已接操作维持，其他仍待。

`ActionSystem` 增加显式原法术数据输入，由 Unity 的原 SpellCardSO 打包上下半文字与费用，经 `PveJourneySession` 传入每场 `PveBattleSession`，不依赖运行环境中的开发目录 JSON。正式效果仍负责昼夜、额外费用、原子支付、伤牌及攻击贡献。修正 PVE 入口未赋值 `EngagedEnemies`，现在烈焰之墙强化按本场实际敌群计加成。

界面按所选上下半显示原文、印刷费用；超过六种选择可翻页。首次魔力箭矢翻页按钮文字高度不足已修复，原选牌面板改不透明以消除背后文字透影。

## 边界与后续

121张目录不是121张完整PVE操作。22种有分支也不是22张全分支通过：魔力结晶/欢悦的回收、魔力牌配合强化、本能移动等仍待；本批只证明上述连续路线，夜间强效和烈焰之墙仅后台通过，后续集中场景再覆盖。部队19/30、神器10/25、自身技能17/70的有限完整场景基线不变。世界移动/地点/招募、正式起始牌库与升级奖励、其他原卡/神器/技能合法操作入口仍需推进。截图/日志仅本地，无远端推送；目标保持 active。
