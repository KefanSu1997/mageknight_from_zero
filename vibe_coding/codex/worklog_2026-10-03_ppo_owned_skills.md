# PPO 自有技能训练扩展

目标保持全原版要素、多回合多轮、最终真实场景验收。此次扩展只修改本地 RL 工具，不修改游戏效果或场景。

在 v4 的207维观察后追加70个原技能的持有、回合已用、轮次已用、翻面状态，保留旧特征语义。新增动作复用 PveBattleSession.UseSkill / PveJourneySession.UseOutsideSkill；只能选择当前真实玩家已取得的技能，通过正式规则可逆预演过滤费用、次数和阶段。需要额外牌、部队、地图或多人输入的入口仍是明确缺口，没有伪造输入。原伤牌选择目前为真实手牌中第一张，敌人/攻击目标目前只有第一个。

正式升级的合法候选按种子变化选择，避免永远选排序第一种技能。实际发动的技能及选项单独记录到 training_coverage.json，持有不算发动覆盖。轨迹增加本人归属和使用次数标记检查；这些检查不能替代每种技能的原文独立数值验收。

初次1024步烟雾训练：13条训练轨迹，实际9种技能选项；定时复查5567条断言零错误。删除没有原入口的无效技能选项后，新动作目录直接由原选项及正式动态选项构造。旧权重按动作语义迁移。

dotnet build 零警告零错误；Unity Console 两次零错误，证据 tmp/rl_owned_skills_console_20261003.json。

下一批：16384步，从种子448继续，输出 AutomationOutputs/BattleRl/20261003_owned_skills_ppo。每条完成轨迹检查，约每60秒额外查看七英雄轨迹，失败立即留证停止。尚待训练结果和评估。

该批已完成：16384步、240条训练轨迹，156.06秒，约104.98步/秒；487维观察、778个语义动作。实际覆盖7英雄、40敌人、100个卡牌效果选项、39种技能的47个选项。范围扩大并改变合法奖励候选，不能直接与v4胜率作公平性能对比。最终小样本评估2/7至少赢过一场、正式回合拒绝0；小样本暂未表明稳定提升，完整483配对评估正在独立进程运行。模型 policy_ppo.npz 可重新加载，约1.07MB，留本地。

仍缺全高级行动、法术、神器、部队、特殊技能输入、多敌人、多攻击槽、地图和新范围真实UI重放。当前后台训练成果不能记为目标完成。

完整配对评估已结束：483条中314条至少赢过一场（65.01%）；2309场战斗完成，469条进入夜间，191条实际完成两轮，292条到达16回合训练上限。正式回合拒绝0；469729条选择性断言零错误；无完全不参战轨迹。全部原技能数值并未逐一独立验证，也没有取得新范围Unity验收。此前v4为309/483，但奖励候选和动作空间改变，不能将5条差值宣称为公平胜率提升。

继续训练计划：同v5范围，从种子689继续32768步，热启动本批模型，输出 AutomationOutputs/BattleRl/20261003_owned_skills_continue_ppo。目的是补技能/敌人实际训练覆盖，保留所有已有证据。每分钟定时审查仍启用；新的法术、神器、部队输入适配另行开发，不会仅靠延长此范围训练而宣称全目标达成。
