# 合作旅程定向后台用例

新增 `Assets/Tests/RulesState/PveCooperativeJourneyTests.cs`，配合主代理的多玩家正式旅程入口改动。

5例覆盖：两实际玩家正式回合切换与原卡费用、战斗真实伤牌和原牌引用归属；旧战斗命令关闭；战术次序反转及真实英雄升级对象切换；两名玩家已持有的独有高级行动/神器不复制入共享供应；重复玩家ID/同一实例拒绝。

用例只使用已有原卡、原敌与正式旅程/战斗入口，没有另写模拟规则。原5例与单人5例由主代理统一运行10/10通过；本代理未运行CLI或Unity。

追加2例针对移动阶段到战斗行动边界：旧移动/影响余点清除，灵动转换许可保留，战内新出原移动牌可兑换并实际攻击消费；非法敌人选择保持池与行动状态。后台结果另等主代理。
