# 接入剩余原部队前先核对原图图标

旧OCR会把影响力图标识别成黑色魔力费用，把获得白晶识别成支付白费，把寒冰抗性写成“神圣”、物抗写成“冲击”，也会漏掉复合招募地点。魔宠的颜色标记增益不等于每次发动的魔力费用，巫师绿色能力不存在旧数据臆造的夜晚限制。

本次核对11张本地原英文图并修正9种原JSON，详见`vibe_coding/codex/pve_remaining_units_original_audit_2026-09-23.md`。先修原数据，再为正式消费者接能力；不因目录/图片/数据已齐就扩大SupportedIds或场景通过数。

运行约束与验收分别记账：用户游戏期间延后Unity，仍可轻量核对原素材/源码；JSON可解析不代表效果验证通过，Unity导入编译与场景门槛保留待执行。新经验只确认原图核对发现，不宣称剩余11种能力已经实现。
