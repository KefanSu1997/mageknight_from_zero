# 魔力汲取与魔力征引：实际公共骰、支付及归还

## 问题与处理

旧实现仅增加额外次数或直接发魔力标记，没有取走真实骰子；强化“不重掷归还”也无对应状态。验证即时标记数量不足以证明整张卡可用。

- CardManaActions.UseSourceDie负责普通/额外额度、实际可用骰和产色。013基础的黑色通用限于它给出的额外骰，不写全局BlackManaWild。
- ManaSource.TurnClaims记录本回合普通、额外、转换骰；RoundClaims继续单独记录魔力宣夺的轮末骰。归还按所有者收集原引用，不仅看单个HeldManaDie。
- 009蓝费、一骰转非金色产2；013白费、两骰各转非金色各产1。选择的真实来源、数量、唯一性与合法颜色在费用前验证。
- ManaDie.TurnTo执行牌面转换，不调用随机；转换骰在回合末以同一实例、转换后的面归还。正常取用骰照常重掷。
- 强化选择集合必须初始化且用Clear清理，便于真实选择流程重复使用；不要让首个选择因null失败。

## 验证方式

后台复用原卡和正式移动/战斗入口。CountingRandom只观察重掷调用次数，不替代规则：基础两枚实际用骰归还调用两次，强化仅普通付款骰调用一次；转换骰原引用和新面保持。所得魔力实际支付原行进和狂怒，再检查逐格费用、承伤、攻击与名望。

## 范围边界

这些证据证明两张原卡的有限基本效果，不代表公共魔力源全规则完成。已有ManaDie.Roll的昼夜过滤尚未更改，场景通过合法原骰初始面验证本卡；全局随机六面生成和多个英雄/额外骰许可组合保留独立缺口。不得把这部分未验范围伪装成全覆盖。
