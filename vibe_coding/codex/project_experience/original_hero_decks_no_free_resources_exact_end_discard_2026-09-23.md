# 原英雄16张起始牌与回合末按实例弃牌

1. 演练快照和原版开局必须是不同入口。原版开局创建16个真实牌实例后正常洗牌，开局抽牌交给GameEngine；不能把“英雄选择”只当名字替换而沿用上次演练晶体、技能、部队与7张指定手牌。
2. 英雄卡底部三颗晶体属于虚拟玩家规则，不能送给正常玩家。来源是本地原入门规则书第5页，不沿用旧摘要数字。
3. 用真实PlayerState.HeroId和Name显示/记录战斗身份。原素材可作为英雄识别，但卡面图不等于独立英雄肖像已完成。
4. 同ID牌是不同物理实例。回合末选弃先整组验证，再用ReferenceEquals/TryDiscardExact处理；不能用record值相等的Contains/Remove选错同名牌。伤牌没有一般回合末弃牌权限。标记不提前改变手牌，已另用于出牌的标记自动取消。
5. 合图不保证全是官方卡。七英雄标准牌库核对发现两张额外矮人牌疑似民间Ymirgh，不能用仓库卡库既有通过数证明官方来源；保留历史证据并分清口径。
6. 随机开局的场景流程可使用“实际手牌第N张”并核对牌区守恒完成，而不必固定一个有利牌序。七英雄后台构成检查加一条真实跨轮旅程，避免重跑全卡库。
