# 原武器弃牌、焚毁与阶段奖励

真实卡区验收必须核对实例身份和总牌数：RemoveFromHand 不等于弃牌；基础武器自身进入已打出区，焚毁则应永久移除。多张弃牌先全部验证，不能处理一张后才发现另一张非法。

相似的额外名望不能共用一次性字段：剑持续回合，弓持续当前阶段，连续击杀不应提前清除。星辰之弓的两种远程修正互斥且按每笔选择；攻城翻倍变远程必须重新检查城防。剑只翻倍攻击阶段的物理贡献，移除物抗不能错误扩展到元素抗性。

后台使用原代码/NUnit 验证这些分支后再执行对应场景。报告通过还要看截图：摘要若遗漏核心有效值、拒绝原因，就只修复并重测受影响 UI 例，不重跑全部后台或所有卡。证据和余项见 `vibe_coding/codex/worklog_2026-09-16_original_weapons.md`。
