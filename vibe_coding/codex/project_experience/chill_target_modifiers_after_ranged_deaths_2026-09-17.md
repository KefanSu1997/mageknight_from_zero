# 删除敌人前迁移其修正，不能让效果随下标转移

冰冻/致命冰冻按原目标停攻、移除火抗或减甲。正式TurnMachine远程阶段会删除击败的敌人，旧修正表却用列表索引，导致存活目标效果丢失、死者效果传给后一敌人。

在远程奖励按旧列表结算之后、删除敌人之前构造存活下标映射，再迁移ActionContext中的敌人修正。存活项转到新位置，死亡项删除；AttackElementChange中的-1表示玩家，必须保留。多个非连续敌人同时死亡需要一起映射，不能边删边套用旧下标。敌人引用未替换，其他基于引用的实际格挡记录不受影响。

用真实原卡冰冻、火球、狂怒及正式阶段调度器复现并验证：目标前面/后面敌人死亡、目标自身死亡、真实承伤、火抗折算、护甲降低、后续击杀；无效和奥术免疫目标在支付蓝/黑魔力以及移动手牌之前拒绝。先本地RulesCli，再场景操作/数值/原卡面核对；只重跑失败和受影响用例。

范围要准确：这里迁移的是ActionContext的敌人修正，不自动证明附身攻击贡献内的来源下标、分次格挡目标历史、跨战斗期限或所有英雄技能。逐项保持待验，不能把基础设施检查当整卡通过。详细运行目录与最终场景结果见 `vibe_coding/codex/worklog_2026-09-17_chill_ranged_targets.md`。
