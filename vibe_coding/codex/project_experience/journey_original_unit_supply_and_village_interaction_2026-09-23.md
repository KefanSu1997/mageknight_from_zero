# 原供应接入连续旅程的注意点

- 不能复用看似同名的旧教学招募：`RecruitmentServiceExtensions` 仍有虚构单位，旧VillageInteraction治疗未扣真实影响力。应走已验证的 `CardUnitActions.TryRecruit` 与正式治疗池消费者。
- 单位卡供应招走不补位，下一轮整列归底再翻。与高级行动/法术立即补位规则不同，不能复用同一补位行为。
- 开始交涉冻结一次声誉修正并占本回合行动；在声誉X时必须先拒绝。交涉期间声誉变化不重新套一次修正。
- 新招单位须沿用实际UnitCard与UnitState。UI若只从开场配置单位数组取原图，会在取得新单位后报错；查全原资产目录才能复用已有部队操作。
- 无情威压减费是可选的，成功使用才付声誉；不使用时保留许可，不能强制代付。消耗该减费时不清掉其他来源折扣。强化重整需支付等级费用，耗竭与创伤分开。
- 原部队费用/招募地点两行文字受中文字体行高影响，47像素不足；保留原图和数字、增加可见文本区域并仅补受影响路线。
