# 连续旅程的真实移动目标、额外蓝费和回收

- 移动 UI 只负责选择实际坐标，费用/通行/原卡修正必须来自 MovementService；不能把演示地图的视觉路径当作实际 PlayerState.Position。
- 新回合必须从持久地图当前位置同步 CurrentTerrain，否则森林等地形相关效果会读到默认平原。按回合清理额外穿湖蓝费许可，不能只依赖“下一次刚好新建Context”。
- 原德鲁伊之道需要指定格或地形，将临时输入传给共享正式出牌入口后恢复；不要让下一张卡继承前一张的选择。
- “移动力0”不代表免费。清风之歌穿湖仍需单独蓝色魔力，面板须显示这项费用及实际魔力余额。规则断言通过后仍要查看画面，发现缺失只补显示链。
- 稳步前进回收选择绑定实际已打出的 DeedCard 引用，先处理回合末回收再正式补牌，不能塞一个同ID新牌伪装回收。
- 已有探索服务可能是占位逻辑；核对后发现随机生成占位怪物时，不复用它作为原版探索。明确区分自定地形布局、原费用消费者与原版板块探索。
- 详见 `vibe_coding/codex/worklog_2026-09-23_journey_travel.md` 及对应证据索引。19个后台、84步136场景断言；额外费用UI另做最小显示复查，错误选牌夹具的失败记录保留。
