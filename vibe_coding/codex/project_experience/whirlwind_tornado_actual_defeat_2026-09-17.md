# 旋风／飓风与统一真实击败记录

发现：原强化旋风只写KillEnemyIndex，没有正式战斗代码消费它。单字段断言会误把“请求击杀”当成“目标实际被消灭”。必须沿着正式敌人存活判定、名望、后续操作及卡区继续验证。

做法：WhirlwindEffect在扣费前验证本场未击败目标、奥术免疫和强化专属Melee阶段。直接消灭走CardCombatActions.DestroyEnemy，与正式阶段机/战斗结算共用ActionContext.DefeatedEnemyIndices。开始新战斗清空；远程压缩敌人列表同步索引；已击败者不能再次承伤/作为攻击或消灭目标，AllKilled检查全部敌人，本次KilledIndices与奖励仅计新增击败。

奖励：直接消灭支付敌人印刷名望及既有“本回合/阶段每击败敌人”通用奖励，不消耗另一原卡产生的攻击，不触发那一笔攻击专属奖励。真实公正之剑焚毁、飓风消灭、狂怒击杀分别验证名望一次性；爆裂护盾已消灭的敌人也不能再次施法刷奖励。

验证：新增17例先复现15个失败，修复后只补测失败；新增费用/已击败目标检查与共享回归分开，后台全通过才进入场景。基础停攻期限使用真正EndTurn/StartTurn后下一场承伤，避免只切换战斗标记充当完整回合。截图需显示逐步实际击败索引、名望、拒绝原因、白黑魔力及手牌/弃牌，不能仅展示KillEnemyIndex。

本轮具体报告与范围见vibe_coding/codex/worklog_2026-09-17_whirlwind_real_defeat.md。完整冒险场景与其他卡牌仍需继续验证，不能凭此经验宣称整卡库完成。

组合夹具教训：场景默认昼夜由起手牌是否强化决定。基础旋风起手、后续再施放强化法术的组合，必须显式配置Night；后台也应重放同一出牌组合。不要把白昼正确拒绝当成引擎回归，更不能绕过昼夜限制让测试通过。

证据顺序：声称直接消灭“不消费已有攻击”时，必须先打出真实攻击卡再消灭目标，检查那一笔AttackProfile保持和余攻前后相同，最后用它击败另一敌人。飓风之后才打狂怒不能证明已有贡献守恒。本轮后台和场景已补此顺序。
