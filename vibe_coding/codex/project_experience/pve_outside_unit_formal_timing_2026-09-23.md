# 连续旅程部队战外入口须独立于旧战斗结果

- 部队图卡及战斗按钮存在，不代表所有能力可用。移动、交涉影响力、战前产魔和下一回合恢复必须连接同一个活跃旅程 Context；旧 PveBattleSession 的 End 面板不能替代。
- facade 只选择原能力种类与时机，费用、耗竭、原数值、治疗点与正式目标校验委托 `CardUnitActions.Use`。移动和私看在行动前；治疗不能被一刀切的 `TurnActionCommitted` 禁止，因为休息后治疗是合法窗口。
- 治疗产点、选择真实伤牌消费和重整为不同操作。错误为治疗塞入部队目标要在支付前拒绝，避免 UI 显示已治疗但仅产点；重整实际伤部队仍不可发动。
- 斥候私看用 `ScoutTarget` 指向现有守军/供应，不公开地图标记；其移动2/两格探索许可不等同完整原板块探索消费者。
- 定向17条同源 RulesCli 通过证据：`AutomationOutputs/RulesState/20260923_100318_20787bba`。这是后台入口证据，Unity UI/Console/场景交由同批集中验证，尚不能增加完整部队场景计数。
