# 旋转立方体测试场景搭建心得

## 背景
- 任务：在独立工作区构建一个可自动化验证的旋转立方体测试场景。
- 约束：无需打开 Unity 编辑器，需手写场景 YAML 并保持批处理可编译。

## 关键做法
1. **脚本与测试先行**：先创建 `RotateCube` 脚本和对应的 `CubeTest`，并手写 `.meta` 保证可被场景引用。
2. **手写场景 YAML**：直接复用 URP 摄像机、光源的组件字段，新增 `RotatingCube` GameObject，并手动指定脚本 GUID。
3. **日志与经验同步**：在 `vibe_coding/codex` 目录即时记录计划和进度，为后续排障提供线索。

## 遇到的问题与解决
- **缺少脚本 GUID**：通过手写 `.meta` 指定固定 GUID，避免等待 Unity 生成。
- **MeshRenderer 材质引用**：使用内置 `Default-Material` 的 GUID `{fileID: 2100000, guid: 0000000000000000f000000000000000, type: 0}` 保证场景可渲染。

## 后续建议
- 若需拓展更多演示对象，可在同一场景中继续复用手写组件模板。
