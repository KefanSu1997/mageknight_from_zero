# 提神漫步：产生移动点不等于可在地图移动

- 依原牌面的明确例外，战斗中本卡仍产生移动点，但不提供治疗。治疗点与地图移动必须经过独立正式消费者，不能立即代替玩家移除英雄伤牌。
- 地图入口自身检查 InBattle，不能只依赖战斗攻击/格挡后才设置的 TurnActionCommitted，否则在首个战斗操作之前仍可跨格。
- 两阶段定位11个失败，再以12个新后台与2个正常地图回归验证。进入场景只运行12新增和2直接受影响旧用例，最终233断言通过；原伤牌预期保留，增加实际治疗动作。
- 战斗移动资源的“笨重”等后续用途尚未实现/联验时明确保留缺口，不能把地图拒绝通过当作全部移动规则通过。
