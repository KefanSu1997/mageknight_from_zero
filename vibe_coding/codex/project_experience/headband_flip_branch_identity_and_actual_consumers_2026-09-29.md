# 头环翻面分支与个人技能状态隔离

原头环的非互动技能范围与克朗原技能正文组合解释，见 `headband_flip_branch_rule_decision_2026-09-29.md`；没有新官方专项FAQ，不把社区解释冒充官方引用。

不要只按 OncePerTurn 循环执行原自有技能：狂乱强化首次会给攻击4并翻个人标记，第二次拒绝，造成头环未出而效果部分提交。Typed UseFlipSkill 在确认前锁定整次分支，共用原Effect核心，仅隔离个人翻面副作用。普通狂乱/伪装合并两次；翻面分支一次；仪式实际枚举ManualFlip，因此明确允许一次，不能当OncePerRound或双token。

公共技能仍由真实升级未选奖励产生，借用不写自有技能列表或个人翻面。返回个人技能正面的option100不属于借用。旧pending普通伪装不得混入新翻面分支。

后台有效46（20新增、26直接影响回归）；首次仪式枚举与普通伪装负声誉夹具失败保留，分别定向补验。三个合法自定五原牌构筑，均由正式首战、升级、回合推进取得公共技能：狂乱攻击4实际击杀；仪式绿临时token1支付行进强化后移动森林；伪装在声誉-1实际村庄交涉支付3影响力治疗首战伤牌，回合末清除许可。不得把自定五牌构筑称为原版随机16牌标准开局。

狂乱选翻面一次4时，旧提示却写“两份攻击”；数值证据有效，修提示后只重放到面板留一张图，原消费者不重验。图与逐步报告及哈希见 `pve_headband_flip_acceptance_index.json`。普通狂乱option0仅本批后台，伪装普通复用旧场景；不扩展成全借用组合已过。
