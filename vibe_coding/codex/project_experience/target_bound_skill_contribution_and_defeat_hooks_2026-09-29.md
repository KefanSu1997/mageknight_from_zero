# 目标限定贡献与真实击败钩子

- 原技能写“对不同敌人各攻击 1”时，应保存每笔实际敌人引用，不生成自由攻击总和；原牌来源、纯技能来源和部队来源分别保留。
- Monster 是 record，同数值不代表同一个敌标记。贡献消费也必须按引用匹配，不能用默认 record 相等性 Remove 导致别的敌人贡献消失。
- 显示、可用贡献过滤、远程与近战底层结算必须共用限制；仅 UI 隐藏错误选择不足以保护底层入口。组攻目标约束和整组抗性分开计算，保持一次取整；目标限定余量不得覆盖别的敌人的护甲。
- 击败后续消费者按顺序执行：登记真实 defeated 索引，再登记候选/来源奖励，最后归还地点供应标记，避免身份消失。部队影响按实际参与的目标与贡献记录，不能因池中有其他目标的单位贡献就判当前敌已受部队影响。
- 新增用例与直接受影响共享规则定向验证即可。本批叉形 13 例与共享回归 8 例后台通过，证据见 `vibe_coding/codex/worklog_2026-09-29_forked_lightning_backend.md`；场景另记。
