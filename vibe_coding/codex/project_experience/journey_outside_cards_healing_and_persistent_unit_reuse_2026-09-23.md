# 战斗外原卡、恢复与同部队再战

- 连续旅程应有独立的战斗外出牌入口，直接使用当前 GameEngine 回合 Context。不能为了给治疗牌一个“End阶段”而创建假战斗或新玩家。
- 原卡选择只描述输入，不复制效果；上半/下半费用走同一个 ActionSystem。显式目标须是自有实际部队，重生多目标采用原效果总等级校验；调用后恢复上下文目标，避免后续牌误用旧目标。
- 治疗点、单位就绪、单位创伤及可发动状态分别观测。原再生可以让受伤单位就绪，但必须继续支付其实际等级的治疗费用，才可再次发动。农民原等级I，不能按图标经验猜为II。
- 连续场景可以保留一次未获胜战斗的真实敌人和受伤部队；恢复后再战，验证的消费者比直接改单位状态更完整。临时魔力先支付、库存晶体后支付也在同流程可见。
- TMP enableAutoSizing 必须设置合理 fontSizeMax；不截断不代表视觉合理。检查实际截图后，只补受影响显示，保留已通过规则路线。
