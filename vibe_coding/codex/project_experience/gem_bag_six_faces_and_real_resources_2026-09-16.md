# 无尽宝石袋：完整骰面与实际资源

- 依据原卡面，卡牌效果的魔力骰不按昼夜过滤。宝石袋必须使用已有 ManaDie.RollUnrestricted；白昼也能掷黑色获得名望，黑夜也能掷金色选择基本色魔晶。不要把魔力源可用颜色的限制套到卡牌随机奖励。
- 复用 ActionContext.EffectRandom 注入结果、LastManaRolls 记录实际骰面，生产默认仍真实随机。用同一效果源码先验证六面与昼夜，再以 Unity 原卡场景核对实际奖励；不能用伪造报告或直接设置结果代替执行。
- 两次金色各自选色，非法选择在掷骰和获得资源前拒绝；不能 Math.Clamp 静默改为另一种选择。魔晶达到三颗后的额外奖励仍通过正式 ManaPool.AddCrystal 变为临时标记。
- 基础/焚毁通过 CardPlayActions.PlayArtifact 消费真实手牌实例；基础在回合末弃掉，焚毁永久移除。焚毁不掷骰，四色加昼夜对应颜色；验证得到的魔力确实可以支付原版狂怒/暴风雪费用，回合末未用标记消失。
- 本轮仅运行 16 个新增后台检查、24 个新增场景案例及一个受共用面板影响的戒指 UI 回归。已通过检查退出日常队列，历史与 partial 范围保持。
