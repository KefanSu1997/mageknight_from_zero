# 新轮面供换底与真实GameEngine

- 原规则第4页2d/e：高级行动与法术新轮都只把最底一张放到对应备用牌库底，其余保留。不要把法术全体未选牌回底当成此规则。
- 轮换不仅要面供数正确，还须证明原最底实体经过备用队列后重新出现。三轮逐步ID和ReferenceEquals能拦住“移出后丢失”及复制新对象的假通过。
- 已取得的卡属于玩家牌区，不再参与公共供给循环；同时验证基础神器回玩家牌库、焚毁和材料保持永久移除。
- 原DiscardPile只用作历史记录时须明确标注，不能在全局实体守恒里重复计入已回备用的同一对象。
- 场景的GameEngine与ActionContext必须共享同一个供给对象；单独建一套演示市场再调用EndRound不能证明原卡的后续结算。同步实际RoundClock而非计算显示数字。
- 组件EndRound通过不代表完整RunOneTurn、战术顺序、玩家完整洗牌或部队市场通过，未覆盖范围继续列出。
