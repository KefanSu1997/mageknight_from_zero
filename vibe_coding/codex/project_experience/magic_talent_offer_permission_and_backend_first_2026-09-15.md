# 魔法天赋：模式分离、真实供给与一次许可

原实现把基础弃牌和强化获取混合，基础只设置SpellColors而没有消费路径。解决时先读原卡，区分“正常打出供给牌”和“获取到弃牌堆”；不能把设置一个标记作为完整效果通过。

1. 强化蓝色费用与额外同色费用通过已有ICardAdditionalManaCost统一支付；选择蓝法术要两份蓝魔力。先验证目标和颜色，费用不足不能先扣一份。
2. 基础弃牌按真实实例验证和精确移除，不能用相等ID的伪造对象代替。颜色来自原定义，不能由option声称。
3. CardSpellActions使用原法术数据和ActionSystem，保留费用及昼夜条件；仅成功后消费一次同色许可。供给牌保持原位，结束回合清理未用许可。
4. 先用同源NUnit后台25项覆盖颜色、费用和生命周期，再跑15个场景检查实际按钮与原卡面。后台0.388秒通过后仅补场景，不为UI检查重复后台参数全排列。
5. 完整卡区生命周期、行动限制仍须联验；本批通过不等于整卡/全库通过。通过断言退出日常队列，partial范围保留在计划中。
