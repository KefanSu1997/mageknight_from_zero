# 荣誉旌旗：真实附着与名望期限

原卡：`Assets/GameData/cards/items_000.png` / `items_en_000.png`；复用 `CardsAssets` 定义及正式 `CardPlayActions`。官方 Ultimate Edition Rule Book（2018）p5 的旗帜说明：每支部队最多一张；替换/销毁/解散时弃掉原旗帜；轮末选择保留或洗回；附着期间不能用焚毁效果。

基础不能写全队临时加成。用 `UnitState.Banner` 保存实际 `DeedCard` 引用及所属玩家；手牌移入附着区，替换旧实例进入弃牌。销毁路径集中调用释放，先清引用再弃牌，防止重复释放复制卡。解散/治疗系统解散/招募替换通过同一销毁路径处理。

`ChooseRoundReturn` 只记录选择，`GameEngine.EndRound` 在实际弃牌洗回前执行释放。保留的附着牌不进牌堆。回收不是立即凭空抽牌。

基础攻防/护甲 +1 只给附着部队；名望按该部队每次成功发动攻防能力计。焚毁给本回合部队加成；每支实际部队限一次名望，各次焚毁来源独立。真实能力使用统一入口，英雄/移动/影响力不加；费用失败或耗竭后拒绝不奖励。后续攻击贡献的拆分/结算不再重复奖励。

供应部队的临时 UnitState 每次不同，奖励身份必须使用实际供应卡引用；UnitCard 是 record，值相等不代表同一张供应实例。列表以 ReferenceEquals 去重，同时区别两张相同定义的实际卡，避免 HashSet 默认值相等折叠。

战斗结束清攻防池，但不清焚毁加成/本回合领奖记录；回合末清。基础附着跨战斗、回合和轮次，伤牌/耗竭不因附着改变。

场景预期要按阶段：受到实际英雄伤害后，手牌计数包括伤牌；再生先加治疗1并重整，随后进入战斗会清除治疗点。分别断言获取与清除，不能把出牌瞬间的数值作为最后阶段预期。
