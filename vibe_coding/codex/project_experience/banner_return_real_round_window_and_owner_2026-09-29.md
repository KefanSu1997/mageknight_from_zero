# 附旗取回必须处于真实轮末窗口

- `ClockTracker.RoundEnded` 在正式EndRound后可能仍保留旧状态；仅凭它开放选择会误入新轮。窗口还须确认本轮已开始、无活动回合、尚未准备新轮。
- 轮末属于所有玩家，不能只列最后行动者的单位或临时切换当前玩家。按本局玩家和单位真实引用验证所有权，分别保存保留/取回。
- 点击取回只修改既有选择集合；真正移动牌区由原 `BannerActions.EndRound` 在正式轮末完成，先释放再洗牌。普通旗保持单位身份与创伤，指挥旗按原Release移除所附部队。
- 下一轮必须验证取回的原牌能再次使用，而不只检查附旗字段变空。默认保留也应跨轮保持原附着且可实际消费。
- 后台与连续场景证据见 `vibe_coding/codex/worklog_2026-09-29_banner_round_return.md`。共享入口的代表验证不等于重测全部六旗所有效果。
