# 魔力技能绑定当次费用、源色与真实材料

魔咒的立即使用要求应由实际消费者付款实现，不能先生成普通 token。两极分化也只替换当次一枚费用，不能设全回合 wild。共享 ManaPool 先对整笔费用生成计划，预览与提交共用；次数、真实材料、源骰额度、剩余其它颜色均通过后才提交，失败不回滚整状态。

真实源色与规则视为色分开：红晶被视为绿支付，SpentCrystals 记录红，诅咒检查绿。日黑源骰与夜金强法术绑定原骰实例与正式取用历史；夜金的黑费仅在强法术目的作用域合法。

不要调用按值比较的 PlayerDeck.Discard 处理用户选中材料：两张同 ID 的 record 相等，可能移除了本体却把另一实体放入弃牌。已验证用 TryDiscardExact 保持实体引用。初批失败证据20260929_051025_036a4875，修复后新增26例通过20260929_051154_5192dac0。

必须先核单位原费用：火焰法师能力0远程3免费，能力1攻击/格挡6才需红费。测试不能因为想测费用而给原免费能力添加成本。

当前内部后付费牌/神器仍明确拒绝本次付款选择，不冒充全部消费者完成；场景证据另记。

UI只保存绑定实际卡/单位的选择，点击原行动确认才进入付款作用域；选择与取消不产生资源。副面板避免覆盖资源与反馈行，付款窗口最后绘制。两回合70有效步/105断言与9关键图见 `vibe_coding/codex/pve_payment_skills_acceptance_index.json`。
