# 正常试玩不能默认小验收牌库，攻击必须保留来源选择

- 五张手牌、零牌库的演练不能作为标准开局推荐。三思后行先抽再洗，选两张后只剩三张是正确规则结果；修入口与预告，不改原规则顺序。标准16牌实际场景仍5手11库。
- 同名卡必须按引用选择，不能用record的Contains/Remove值相等代表实体。换牌确认后需要保留实际补抽反馈；统一Act在执行前清旧反馈，不能执行后清掉新成功信息。
- 合计攻击资源不足以支持玩家分组操作。需要实际来源列表并逐次提交原引用；未选贡献保留、不拆单笔、不返超额。防护流程与普通攻击共用同一选中贡献；预览和结算必须使用同一个筛选。
- 默认选全兼容现有简单战斗，玩家可保留部分给下一怪；一次结算后清UI分配，仍由正式池保存剩余。
- 原英雄技能必须核对原HeroId和技能池，不能因为裸后端可添加技能就把它当成合法构筑。首轮验收误将pool000炽热剑术归给诺洛瓦斯，被正式UI重整技能正确拒绝；改阿瑞希亚，保留失败报告，修正后补验。
- 手牌分页占独立底部空间，避免与治疗、弓选择、手牌恢复按钮重叠；悬停大图无raycast，不能挡住真实目标操作。
