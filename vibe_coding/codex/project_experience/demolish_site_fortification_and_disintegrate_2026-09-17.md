# 拆毁、解离：地点城防和怪物城防必须分开

原依据：`Assets/GameData/cards/magic_en_007.png`、同目录中文原卡面和 `resources/text_json/magic.json`，以及原规则的红色效果/火抗、奥术免疫规则。

1. “Ignore site fortifications”不能复用无范围的 IgnoreFortified。单独的 IgnoreSiteFortifications 只抵消地点层；地点+怪物双重城防变为怪物自身一层，仍须攻城。地点效果不是施加于敌人，因此火抗/奥术免疫不能保住地点城防。
2. 基础与强化不是附加关系。解离不授予地点城防许可，仅攻击阶段可打出；先验证有效存活目标和红色效果免疫，再整笔付费，实际调用共享 DestroyEnemy 登记击败与名望。重复目标不扣费用、不减其他敌人护甲。
3. 减甲需要累加、最低1，并跳过已击败和有适用免疫的敌人。正式冰冻基础的去火抗可让解离合法选中目标；冰冻强化仅减甲，不能拿错分支当去火抗测试。
4. 效果期限到回合末，不能在 EndBattle 提前清，也不能漏掉 EndTurn.SkipDraw 的提前返回路径。断言实际护甲恢复、地点许可清除及原卡实例转移到弃牌。
5. 缺魔力不等于缺支付资源。场景有默认魔晶，后台默认无魔晶；缺费夹具必须显式设置对应魔晶。应额外保留整笔费用不足时的魔晶原子性、合法魔晶支付分支。不得为让测试过而破坏正式支付。
6. 场景最终显示必须包含关键魔晶数值，不能只把其消费记在JSON中；新增显示只补验直接相关场景，不重跑整个库。
