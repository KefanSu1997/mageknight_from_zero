# 活力焕发：选项和重整目标必须先验后付费

- 按原牌面的效果类型图标判断时机；仅有治疗图标的活力焕发，抽牌/绿色资源/重整分支也不能在战斗中使用。
- ICardEffectValidator 在 ActionSystem 付费前检查非法选项与部队目标；效果直接调用也验证。重整必须验证自有实例、未销毁及印刷等级，不能只看同卡ID或不满足时静默跳过。
- 治疗与重整独立：治疗点可以选择真实部队，按等级消费但不自动重整；重整保留伤牌，CanActivate仍为false。
- .NET 23/23之后才进入Unity25例601断言。实际截图发现长拒绝提示覆盖目标卡，缩短重复状态栏并保留正文原因，仅重验一例。自动textFits不包含全部跨控件遮挡，数值全通过不能替代看图。
