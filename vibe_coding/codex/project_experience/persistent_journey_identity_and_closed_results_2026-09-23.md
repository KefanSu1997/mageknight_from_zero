# 连续会话沿用玩家、牌与原敌实体，旧战果不可写

`PveJourneySession` 将正式 `GameEngine` 与已有 `PveBattleSession` 接在一起；只在开始新回合建立新上下文，不在下一场战斗重建玩家。补牌、归还骰、资源/次数清理及新轮继续用已有服务。

- 新普通战斗必须有活动回合且未用行动，活动战斗不得覆盖。传入空/重复/已击败的实际原敌标记在行动消费前拒绝。
- `Monster` 是record，默认集合相等会混淆同牌面的不同物理标记；已击败记录必须用 `ReferenceEquals`。测试明确验证同实体拒绝、同值另一实体允许。
- 仅保存旧战斗结果不够：旧UI可能持有旧session继续治疗或用神器。给所有18个修改入口接回合有效性检查，结果仍可读，结束回合后持续拒绝修改。
- 两战→两回合→新轮必须检查同牌实例、实际费用、实际弃牌/补牌以及受伤部队未自动治疗。后台通过不能代替控制器与场景真正接入。
