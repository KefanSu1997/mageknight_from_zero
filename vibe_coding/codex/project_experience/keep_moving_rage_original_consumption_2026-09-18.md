# 永不止步与战斗之怒的正常后续消费

- 永不止步的“提供移动力的下一张／其后每张”包括其他原效果类和横置，不能仅在MoveEffect中加值。奖励在正式出牌完成处依据出牌前许可快照处理，避免新许可反哺自身；基础许可只有实际产生移动才消费。
- 横置仍属于本回合已打出原牌。旧入口先RemoveFromHand再Discard，后者找不到手牌，会丢失实例。先检查持有与合法性，再TryPutInPlay原子移牌；测试核对同一实例在Played，最后移动池实际消费。
- 战斗之怒按本场“收到”的伤牌累计，不只看当前伤牌库存，也不只看出牌后的伤。复用ActionContext战斗伤牌计数，在出牌和实际入手伤牌结算时补累计奖励差值，整场共享一次上限。
- 原卡基础最多+1，强化最多+4；分次敌人承伤不能刷新上限。战斗结束/回合结束必须清理奖励许可，不能继承到下一战斗。
