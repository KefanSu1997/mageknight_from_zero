# 野蛮收获：把弃牌收获绑定到一次真实移动

原效果只设置HarvestTriggers和移动力，没有读取次数的消费者。基本验收不能只检查字段增加，必须证明移动、原材料弃牌、所得魔晶实际支付后续卡牌。

正式MovementService.TryMoveUsingPool增加可选harvestCard/harvestColor；无材料时保留原移动行为。材料是该次移动的选择，不建立可延后使用的收获窗口：

1. 移动前验证次数、真实手牌引用与颜色。行动/法术按原CardColorHelper取色；神器需要明确选择红蓝绿白之一。
2. 复用原邻格、地形、费用和战斗限制检查；失败时不弃牌、不发晶、不扣收获次数。
3. 只有成功移动才调用内部CardHarvestActions.Resolve，用TryDiscardExact把同一实体放进弃牌区，再AddCrystal。基础次数减一，强化保持每格许可；同坐标第二次调用不是新移动，不能再次得晶。
4. 回合结束通过ClearMovementAndReadyEffects清许可；未选择材料可以正常继续移动，不强迫玩家收获。

公正之剑items_008在此只是原神器材料；任选红晶属于003牌面必要选择，弃牌不能执行武器效果，也不能永久移除。两主例分别将绿晶支付原行进、红晶支付原狂怒，经正式地图和战斗消费。

后台证据20260918_014248_860f45b2：003五项加普通移动直接受影响回归一项，6/6通过。首编译遗漏Data命名空间在执行前补正。场景结果见同日基本验收工作日志，不把后台通过单独记成整卡基本通过。

后续复用：凡规则写明“移动时可做”的可选交易，优先绑定实际移动命令，避免仅在上下文放一个长期可用标记。独立断言同时覆盖位置、池费用、原材料引用和结果资源；只扩本次受影响范围。
