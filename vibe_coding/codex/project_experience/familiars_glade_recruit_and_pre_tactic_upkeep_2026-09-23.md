# 魔宠的空地招募与战术前维持

- 原卡上的色标是部队实体状态，不是玩家临时魔力；能力不再次收费，只按招募/维持留下的颜色改变数值。
- 原扩展规则对空地招募明确“不算交涉”。不能仅给RecruitLocation加枚举后直接复用交涉入口，否则声誉与交涉奖励都会错误生效；仍占该回合行动。
- 招募额外魔力必须放在地点、影响力与指挥槽整笔校验后。实际魔力可由临时标记/晶体支付；新轮维持明确要求库存晶体，不可复用token-first付魔力函数。
- 新轮准备与战术提交分开：补牌/重整一次 → 魔宠逐实体维持或移除 → 战术顺序。不能为展示新轮而重建玩家，不能在失败或补选时重复补牌/重整。
- 新轮重整、维持不治疗。两份同名部队各自保存颜色/待支付状态；放弃维持只移除所选实例。
