# 原卡选敌、互斥效果与实际攻击减值

- 已有正式效果不等于可玩入口：`PveBattleSession.Play` 原来只传固定 option，因此需要敌人索引的法术根本不能按玩家选择执行。让选项明确声明单敌索引/敌人攻击槽/无目标，先验证实际存活目标，再把输入交给原效果。
- 单敌选择不能默认猜敌人 0。群体暴露的去城防/去抗性、震颤的单体/全体是互斥分支；解离、飓风必须保留近战限制。印刷蓝/白择一不等于同时支付两色，也不由剩余库存替玩家选择。
- 一次出牌的 SelectedEnemy、SelectedEnemyAttackIndex、SelectedActionManaColor 使用 try/finally 恢复，避免失败残留或串到另一张卡。效果数值、费用、免疫、奖励全部复用正式服务。
- 实际场景暴露了仅后台无法发现的问题：旧“点敌人”处理器清空所选卡与选项，导致确认按钮消失。针对需要选敌的卡保留卡/模式，并每次只选择一个实际敌人；普通合并攻击、恐惧旌旗多选仍沿用各自逻辑。
- 减攻必须消耗实际次数并绑定敌人攻击槽，再由同一个 DefenseProfile 进入显示、迅捷格挡和承伤。已解决或停攻的攻击拒绝消费。迂回躲避奖励由实际承伤阶段触发，不能在打牌时提前发攻击点。
- 原型的多个停攻机制需要正确呈现：冷峻目光按敌人实体保存，不能只检查 SkipAttackIndices 就断言没有停攻。
- 迂回躲避等长原文不能只保留开头：固定反馈区设置字号范围 16–22，实际截图和 TMP 截断检查同时确认完整规则，而不是删文或取消断言。
- 新增迅捷反应测试误给白色费用的失败按原蓝色费用修复夹具，仅补失败；场景保留选敌问题失败，并从受影响选择步骤重放，不重复前缀断言/截图。具体报告、覆盖与未验范围见 `vibe_coding/codex/worklog_2026-09-23_targeted_deeds.md`。
