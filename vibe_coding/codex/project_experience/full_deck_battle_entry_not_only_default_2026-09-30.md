# 换牌回归必须覆盖玩家实际开局入口

现象：用户按英雄页中间“以此英雄开始已选构筑”进入兽人战团，三思后行换两张仍只剩3张，牌库2。后台正式16牌开局和标准地图入口此前均通过，但该按钮仍用空牌库、5张手牌的演练构筑。

修复：英雄页两种主要玩法统一通过原英雄 CreatePlayer 初始化完整16牌；地图模式分别设置。旧小牌库继续作为明确标注的高级演练入口，保留既有按钮ID和可重放用例。禁止改三思后行的先抽后洗顺序或凭空补牌来掩盖开局数据错误。

验收：针对用户实际英雄阿瑞希亚和战斗试玩入口，核对初始5/11、红蓝晶0，换2后5/11，正式开始回合再进入兽人战团仍5/11。后台通过不代表所有可见开局按钮均使用该后台初始化；UI回归须包含造成缺陷的入口，不只覆盖正确的另一条路径。结果见 worklog_2026-09-30_full_deck_battle_entry.md。
