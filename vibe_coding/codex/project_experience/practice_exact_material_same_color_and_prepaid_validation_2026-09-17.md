# 修行：去除原牌、同色供给与支付前校验

- 换牌效果必须检查实际手牌引用和原行动牌定义，不靠 CardType 字段或颜色查表单独证明原卡身份。按引用永久移除，避免同ID record的值相等误伤另一实例。
- 用现有 ICardEffectValidator 在正式 ActionSystem 扣强化费用之前拒绝非法材料、索引与供给；不能在效果中先删材料，再发现市场不存在或颜色不符。
- 不能把玩家越界选项 Math.Clamp 成另一张牌。显式第二供给、未选实体保留、备用牌即时补位分别核对。
- 基础获得卡到弃牌，强化到手牌；后续实际出牌验证可用性，比仅检查手牌数量更能证明规则。结束回合再核对修行本身、取得卡与永久移除材料的去向。
- 牌区接口的顺序契约与原规则去向分开核对：PlayerDeck.DiscardPile按牌顶到牌底返回，最后弃入的牌在前。不可把时间顺序写成接口预期；先补后台顺序断言，保留原失败报告，再仅修正并补测对应场景，不为通过修改实际游戏规则。
- 复用现有原素材/供给视图时限定到明确场景分支，分别显示手牌、弃牌、移除和绿色费用；新增字段保留旧观察键兼容历史证据。
