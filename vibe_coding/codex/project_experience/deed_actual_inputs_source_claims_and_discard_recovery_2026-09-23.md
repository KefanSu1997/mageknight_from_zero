# 原卡实际输入、源骰额度与跨回合弃牌回收

- 战斗与战外共用选择对象，把实际源骰引用、实际手牌/弃牌引用、各自独立颜色和可选转晶交给原 CardPlayActions。临时 ActionContext 输入在成功和失败后都恢复，避免下一张牌继承前一张的材料。
- 原随机应变必须在费用前验证实际非伤材料；自弃、外来实例和伤牌失败不能先扣强化红费。不新写演示规则，补到正式效果的 ICardEffectValidator。
- 原普通源骰与额外额度分别消费，原实例被持有并在正式回合末归还。转换骰不重掷；魔力风暴只重掷仍在源中的真实骰。显式重放种子用于正式随机源，默认仍随机。
- 魔晶精通只返还本回合实际花费的魔晶，不能把夹具初始化的支付当原消费；第二回合的支付不应再退款。
- 强化神游的黑标必须在施法回合通过实际来源取得；上一回合的临时标记会正式清空。失败夹具应修正来源，不能放宽规则。
- 冥想回收上一回合的实际弃牌，再经过正式补牌进入下一回合，才能证明回收有真实消费者。仅验证牌库计数不够，应同时检查卡身份、手牌、弃牌与伤牌守恒。
- UI选色数组扩展后同步使用数组长度；只补显示/点击检查，复用已通过数值链证据。四基本色用于魔宠维持等限制场合，不盲目全局替换。
