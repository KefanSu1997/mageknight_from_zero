# 正式调度器的阶段收尾与原卡贯穿验收

- 注释不能代替状态机：GameState.NextPhase从AssignDamage只到Melee。一次同时处理伤害和近战的ResolveBattle应成功后推进到End并调用既有EndBattle，否则下一场仍可能借到旧状态。
- 完整远程阶段结束时应消费context的远程和攻城贡献，包括放弃分配的部分。实际原火球5/攻城火8、红黑费用与自伤、远程击杀/不足/放弃、重复结算及下一场攻击共同验证；不能仅断言phase枚举变化。
- BeginBattle仅接受None/End，不允许在同一场中重复初始化阶段。失败调用要检验真实伤牌、名望、资源和GameState未被错误推进。
- 场景新增配置选择正式TurnMachine，目标分配来自真实CombatPowerPool，保留原卡/原效果/真实卡区。规则和预期仍由独立配置给出，UI同时呈现阶段操作和状态。
- UI顶部若保留最后一步之前的快照，会出现回合末已打出区的上下数字不一致。完成时同步最终顶部状态，并实际查看截图；不能只依赖JSON断言。
- 该调度器通过不等于所有上层已接通：冒险5基础卡适配器仍创建临时context、使用独立卡区，其他原卡尚不支持；远程击杀后的目标索引迁移、分阶段格挡奖励依旧单独列为未完成。
