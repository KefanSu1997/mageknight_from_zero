# 激励真实名望、跨回合限制与重整旗鼓实际目标

- 原激励比较 Fame，不比较 Reputation；严格最低排除平手。奖励四种魔力或Wolfhawk名望，先抽实际牌库两张，牌库不足时不伪造牌。
- “下回合结束前不能使用其它激励”属于玩家持久状态，不是单张技能的 OncePerRound。通过正式本人回合开始/最终完成计数，当前本人回合发动与其他回合发动区分；回合结束的升级选择尚未完成时不能提前解锁，新轮不能清除这个锁。
- 重整旗鼓须预校验实际自有部队及需要治疗/重整的状态；静默return会令SkillActions记录一次使用，必须拒绝且守恒。治疗沿用CardHealing.HealUnit，保留治疗历史及正式痊愈许可消费者。两种效果不能混成“重整同时治疗”。
- UI目标取真实UnitState；调用前暂存Context.TargetUnit，并在finally恢复，避免本次技能目标污染下张卡。
- 真实抽牌验收需有真实牌库。通用英雄构筑复用原16张牌及原洗混，只有已配置重放的起点复用种子，正常游戏不固定；不临时复制新牌或重建回合。
- 场景脚本曾误把敏捷强化写成移动4。正式原卡仅战斗阶段远程3正确拒绝，保留失败并改实际路线使用该白标远程攻击，不修改规则适配脚本。有效前缀保留，只补后段。
