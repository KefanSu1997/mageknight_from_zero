# 长回报窗口必须保留真实终止边界

模型回避战斗时，先区分固定执行与概率采样，再检查回报传播，不能原样加时或把单击杀写为胜利。v42两种执行均0/7，保留的224条训练轨迹只有4次完整胜利，65条未开战。

GAE含gamma和lambda的乘积；0.97*0.95使100步之前的终止失败信号几乎消失。调整为0.995/0.99是可测实验，不是胜率保证。参数记录进manifest/metrics，默认保持原行为。独立测试必须覆盖真实done不跨局、非终止截断bootstrap、lambda=1手算、旧默认逐值一致和非法参数拒绝；不能只测试新数值变大。

实验继续使用全部原要素和正式规则，不删除休息、强制结算或免付费用。新配置只在新进程中生效，活进程命令/manifest才是配置证据。旧失败评估、覆盖缺口和最终Unity门禁分别保留。
