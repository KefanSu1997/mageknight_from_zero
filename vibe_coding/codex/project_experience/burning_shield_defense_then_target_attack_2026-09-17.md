# 燃烧护盾的格挡后攻击选择

- 原牌明确允许成功格挡后在攻击阶段作为火焰攻击4使用。把格挡和预先生成的攻击一次提交，会错过奖励生成后的目标选择窗口；不能靠预先手填攻击值通过测试。
- 正式调度器提供ResolveDefense → Attack（可多次选择）→ FinishBattle。防御调用原结算器，保留生成的原元素攻击，攻击调用原CardCombatActions，最终确认才清理未用奖励。重复防御与结束由阶段校验拒绝。
- 爆破护盾的消灭也必须记录在同场已击败目标中，否则下一次攻击可重复领名望。拒绝已击败目标不消费真实原狂怒产生的攻击，换目标后正常消费。
- 火焰格挡成功后给玩家的火焰攻击奖励，不因被格挡敌人的奥术免疫取消；后续攻击仍按新目标的火抗折算。强化消灭属于对敌效果，需要检验火抗及奥术免疫。
- 后台与场景分别记录：实际原卡费用/卡区、格挡是否成功、剩余攻击4、换目标后的有效4或2、击杀与名望、无重复伤害、结束后的奖励失效及真实弃牌。
- 其他Pending击杀奖励期限、远程阶段移除敌人索引和Adventure卡区整合仍未验证，不因这张卡贯穿调度器而声称全部完成。
