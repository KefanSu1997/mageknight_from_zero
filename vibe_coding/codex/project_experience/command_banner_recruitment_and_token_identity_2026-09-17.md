# 指挥旌旗：本回合招募身份与指挥标记

原卡 `Assets/GameData/cards/items_en_017.png` / `items_017.png`：基础影响力4，可将旗帜分配给本回合招募的部队，代替指挥标记。耗竭/重整时旗帜随部队翻面。Lost Legion规则p5补充：失旗（被夺、换旗或轮末回收）移除该部队，即使有空闲普通标记也不能接管。

正式规则来源：https://www.mageknight.net/wp-content/uploads/Mage-Knight-Board-Game-Expansion-The-Lost-Legion-Rules-2013.pdf 。直接读取超时后通过该官方PDF的搜索索引确认NEW BANNERS段落，不依赖其他游戏同名装备规则。

不要把基础效果写成 `TempCommandSlots++`。保持普通CommandSlots，FreeSlots只扣消耗普通标记的部队；独立统计BannerCommandCount。旗帜只能支撑它实际附着的那一支部队。

通过真实手牌出牌后登记本回合的旗帜实例；正常招募和免费取得均记录实际UnitState引用。可在招募前明确预选旗帜，满编时完成招募即从已打出区附着；也可对本回合刚招募的部队事后附着，释放其普通标记。旧部队、同ID伪造实例、已弃掉/已附着旗帜或上一回合招募记录都不能绕过身份与时机校验。

招募失败不能消费旗帜、影响力或供应。取消预选不增加槽位。使用旗帜招募与同时解散互斥；解散一个本来由旗帜指挥的部队不会释放普通指挥槽，不能用来满足满编普通免费招募的替换要求。

释放旗帜时先清引用、把旧牌送入弃牌，再移除指挥部队。Destroy先设置销毁状态再释放，避免递归释放重复弃牌。给指挥部队尝试换荣誉旗帜时旧部队先离场，新旗帜无目标可附着而保留原牌区。轮末选择回收后实际洗回；不选择则跨轮保留。

场景夹具玩家属性需用 `player:` 前缀，例如 `player:ExtraCommandSlots`。未知字段会在准备下一用例时形成运行时错误。监控必须独立检查report.json，即使没有最终effects.json；本次执行器已正常写出failed并停止，无需凭推测重启或修改执行器。

失败整场不等于之前每个已完成用例都无证据。对不可变检查点逐例核对当前独立预期、原卡断言、请求中的完整UI序列、真实命中、断言和最终截图，仅保留错误发生前的完整用例；全场仍为failed。索引明确标 `audited-completed-checkpoint`，不能伪造全量effects成功或把未执行部分标通过。
