# 大地之子：多选一效果的治疗池迁移

- 原版治疗数值是可选择英雄或部队消费的治疗点；不能在选中卡牌效果时直接替玩家治疗英雄。复用 HealingPowerPool/CardHealing.Spend，部队按等级付点，治疗不自动重整。
- 多分支卡仅给治疗选项启用治疗面板；移动、格挡仍使用各自实际消费者和显示，不能因统一 UI 覆盖而丢失战斗/地图证据。
- 后台先以实际卡实例与正式效果复现，再只替换治疗分支。旧场景保留独立最终伤牌预期、增加消费动作，而不是放宽预期适配错误实现。
- 本批16后台通过，13场景271断言通过。后台新增的移动/格挡组合和重打拒绝不自动视为新增场景已验；既有六地形格挡证据保留。
- Unity 动态字体可能在运行中写入带尾空格的 YAML；全工作区 diff --check 的生成资产问题须如实记录，与手写代码检查分开，勿无关改写大字体资产。
