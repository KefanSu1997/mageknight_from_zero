# 正式回合不能靠空过刷新

- 最少出牌/弃牌要求放在共用GameEngine结束入口，且先于资源清理与奖励；不能仅在Unity禁按钮，否则其他调用仍可绕过。
- 用真实牌区操作记数，正式开始回合重置；不要仅看已打出列表，因为附旗、焚毁、已回收的原牌可能不留在该列表。新取得伤牌进入弃牌区不算从手牌弃牌。
- 非伤牌的回合末选择应先验证实际引用和重复，再暂存；按原规则在回合奖励后、补牌前弃掉。拒绝不能耗资源或重置技能。
- 手/牌库双空且已倒数时，跳过是推进轮次，不是开始并结束一次空回合。不能给起手魔力、恢复次数或调用补牌来模拟跳过。
- 共享回合限制会揭露旧测试空过。修正真实消费前提后仍要保留原断言；例如积蓄力量必须为每次真实弃牌后的补牌留足牌库，不能删除蓄牌检查来凑通过。
- 验收字段不存在应修正配置，不给正式状态添加重复别名掩盖错误。失败报告保留；重放实际输入恢复失败边界，只补尾段断言和截图。
