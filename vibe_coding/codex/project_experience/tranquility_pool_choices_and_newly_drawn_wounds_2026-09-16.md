# 宁静：治疗池、互斥选择、圣杯来源与新抽伤牌

- 宁静治疗分支先获得可分配治疗点，不自动选择英雄。复用 HealingPowerPool，可和圣杯组合治疗原三级部队；普通点不产生圣杯名望。原宁静/圣杯/部队定义和卡面保持不变。
- 治疗/抽牌必须明确二选一，非法选项与战斗限制在支付绿色费用前检查；不得把任意非零选项当作抽牌。手形图标限制宁静整张卡，不能在战斗中改选抽牌绕过。
- 旧即时治疗测试保留实际伤牌预期，通过增加明确消费步骤达成；无伤时留下未用治疗点，不产生抽牌。抽牌数量受真实牌库剩余限制，不自动洗弃牌。
- 后台真实牌区验证“治疗一伤抽到新伤，再治疗新伤”，随后用场景按顺序执行两次治疗。用 initialDrawCards 声明实际牌库输入，不能直接写最终结果；最终治疗点6→4、伤牌1→1→0、牌库2→1→0。
- 本批只运行18项新增/直接影响后台检查、25个宁静案例和3个受影响或新增圣杯案例；没有重跑全卡库。其他直接治疗效果还需按卡迁移，不能据此宣称全部治疗系统完成。
