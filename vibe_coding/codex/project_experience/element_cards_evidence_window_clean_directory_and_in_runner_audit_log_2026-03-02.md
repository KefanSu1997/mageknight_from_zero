# ElementCards evidence closure: clean screenshot directory + in-run audit/log writes (2026-03-02)

## Problem

Reviewer rejected runs where:

- `review_bundle/artifacts/screenshots` contained stale `_montage_*.png` from older rounds.
- `element_cards_binding_audit.json` and `scene_automation_console_log.json` were written after `report.finishedAt`, so they were outside the declared run window.

## Root Cause

1. Screenshot cleanup only deleted known `000-008` targets, not all files in evidence directory.
2. Audit/console artifacts were generated by post-processing after automation, not during the same run.

## Fix

Implemented directly inside `ElementCardsManualCaptureRunner`:

1. At run start, delete all files in the screenshots evidence directory.
2. Generate and write `element_cards_binding_audit.json` before playmode exit.
3. Capture SceneAutomation lines during execution and write `scene_automation_console_log.json` before playmode exit.
4. Set `report.finishedAt` with a short margin and ensure report/audit/log writes complete inside the same window.

## Why this works

- Evidence directory no longer contains cross-round files by default.
- Audit/log are now first-class outputs of the single automation run, not late derived artifacts.
- Machine checks based on write-time window (`startedAt~finishedAt`) become deterministic.

## Validation checklist

1. `screenshots` directory contains only `000-008`.
2. `element_cards_report.json.status == "success"`.
3. Write times of `report`, `binding_audit`, `console_log`, and all `000-008` screenshots are within `report.startedAt~report.finishedAt`.
4. Dual compile scans (`error`, `count=1000`, `include_stacktrace=true`) both return 0 and are dual-written to compile status files.
