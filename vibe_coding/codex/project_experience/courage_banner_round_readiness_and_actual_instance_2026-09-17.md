# 勇气旌旗：附着、次数与就绪是三个状态

原勇气旌旗items_003基础先附着实际手牌到自有部队，不在附着时直接重整。战斗外主动发动才消耗本轮一次，调用正式Ready；战斗中不能静默成功或移动牌区。焚毁战斗外重整全部自有部队并永久移除真实卡。

记录次数使用实际DeedCard引用，不能只记录卡ID或部队是否就绪。同ID第二张独立使用；同一实体本轮弃牌、抽回、再附着仍已用。回合末不能恢复，实际新轮才重置。PvP实体转移还需在对应流程中完整延续次数，当前不宣称已经完成。

Ready只恢复指挥标记，不治疗伤牌。伤牌存在时CanActivate仍为false；焚毁不治疗英雄、复活部队或波及其他玩家。复用已有UnitState和CardUnitActions，避免测试另写一份规则。

有真实后续操作的场景要逐步推算所有最终资源。例如原农民发动移动2后，默认MovementPool=0必须被独立预期2覆盖。发生此类夹具遗漏时保留首轮失败，依据原牌面修正预期；只补测失败例，未改动通过例通过逐例证据审计保留。套件hash变化时筛选器拒绝旧报告是保护行为，不应绕过它改报告；显式选择受影响ID。
