# 基本验收边界与原卡主效果补齐

- 用户要求基本验收时，单独记录有限规则清单：基础/强化主效果、费用、必要选择、正常目标与一次直接结算。全规则partial不应自动变成无止境待测队列；保留原边界状态，复用其他原卡场景中的真实跟随出牌证据。
- 子代理按卡类别审计、按明确文件所有权实现；Unity和后台编译由主代理统一串行执行，避免同时写生成器、抢编辑器或高内存并发。
- 欢悦魔晶回手必须保存实际Played卡实例及当次模式。选择材料后，在回合结束补牌前验证并弃材料、原卡回手；基础与强化能否弃伤牌分开。
- 魔力熔毁要按结算前晶体判断无晶者，包含施法者；随机结果产生后才能选实际丢失颜色。测试场景务必清空不用的CardToRemove/CardToDiscard/CardsToDiscard，并与后台统一当前地形，避免旧夹具绑定或森林加成制造假失败。
- 灵魂收割者普通奖励归属实际攻击贡献，焚毁奖励属于当前阶段，使用现有AttackProfile与结算奖励透传；原文永远可选白色也属于基本选择。多抗/多个来源独立选色可明确留扩展范围。
- 旧测试若换了敌人列表却重用已击败索引，应保留同场实际列表选幸存目标，不能清空击败记录或放宽规则。
