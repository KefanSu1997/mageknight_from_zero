# 原特殊魔力、持续技能次数与真实分页

两极分化的昼黑/夜金消费者可用同一原黑暗护符正常使用产生实际标记，再经正式轮末弃洗抽进入黑夜。昼黑支付敏捷白费；夜金支付原火焰风暴黑费，红晶额外费用与真实自伤仍要核对。无需改源骰、fixture或伪造特殊魔力。后台按引用核同一原牌，场景核同玩家、牌区和正式轮次，不把字符串ID相同当物理实例证明。

Wolfhawk洞悉原规则为每轮一次。下一个正式回合仍已用；测试误期望恢复时应对照原规则修正测试，不能修改生产重置频率。原004物理/冰双抗只移物抗，物理4真实击杀护甲4，同时保留冰抗，证明实际消费者而非仅改说明。

战斗技能面板一次只显示一个技能。选择第二技能前须点既有`Skills/Btn_NextSkill`；不能假设存在所有`Btn_Skill_N`。失败保留，重放前缀不重新断言截图，仅补失败后缀。手牌分页同理。

战外与战斗观察键并非完全相同：战外HeroBuild后的技能来源已有`upgrade.skillSources`，`skills.ids`只在战斗快照存在。应使用实际已有只读观察键，保持原SourceId期望，不为测试便利新增生产字段或删除身份验证。

三枚神器颜色的真实默认是红、蓝、白，不是全部红。枚举的真实顺序是红、蓝、绿、白、金、黑，白索引为3；黑暗护符焚毁要选黑、黑、红，分别点5、4、3次。主代理首次修正时误认白索引为2，导致多点一次变蓝，失败亦保留；必须同时读取默认数组和实际枚举，不能猜顺序。选色失败应修正脚本输入、保留原预期费用，变化后的输入段从前一个稳定状态重放补验，不能把错误颜色输入的成功按钮点击算作最终通过证据。
