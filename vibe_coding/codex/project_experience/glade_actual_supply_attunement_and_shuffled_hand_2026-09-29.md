# 林地招募、色标与真实洗牌后的操作选择

- 林地魔宠招募是行动，不属于交涉；必须检查真实站位与实际供应引用，复用正式招募服务。不能把村庄声誉修正或结束交涉按钮带进林地。
- 林地开始得到金色临时标记，不代表已具备白色费用。后台夹具也要调用正式金转白，不能为测试放宽付款规则。
- 五原牌自定构筑使实际牌库为空，可通过正式宣布轮结束逐轮轮换供应，直到第五轮魔宠出现。不能为节约场景步骤伪造供应或重建单位。
- 正式跨轮会洗牌。自动化按可见原卡图片ID定位唯一实际按钮，遇同ID多张拒绝歧义；不要依赖固定手牌槽或改正式随机规则。
- 招募色标、待维持、新轮库存付款和后续能力消费分别观测。连续报告中的运行实例标识用于核对同实体；界面也需显示当前调谐，后台有值不等于玩家可见。
