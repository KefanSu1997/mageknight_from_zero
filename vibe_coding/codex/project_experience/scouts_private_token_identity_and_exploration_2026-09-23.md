# 斥候私看不等于公开翻面

- 原图两项靴子能力属于移动阶段。私看目标使用实际地图坐标/序号或供应颜色，不使用传入的任意怪物副本。
- 私看仅保存玩家观察结果，不写地图公开揭示集合，不从敌堆抽牌；供应Peek与Draw共用同颜色顶标记和抽空洗回逻辑。
- 击败奖励必须绑定引用并在正式三类击败入口消费。按ID匹配会误奖同名另一实体；只在UI增名望则会漏正式远程/近战/直接消灭结果。回合末清理未消费奖励，不在战末过早清除。
- 两格探索只延伸探索范围，仍花2移动、抽真实地块、验证放置；不能直接开SpaceBendingActive，否则会错误开放跳格移动。
- 原敌人JSON部分尚无TokenColor，正式供应拒绝是合理校验。测试必须选择颜色和牌面已核实的原敌人，不放宽构造器或猜颜色；敌人数值变化后使用对应真实费用与足够攻击的原卡。
- 有效本批40案例见 `worklog_2026-09-23_scouts_private_peek.md`，失败报告全部保留并只补失败/受影响项。Unity Console双0：`tmp/pve_20260923_scouts_console.json`。场景及完整原遗迹/板块仍待，不以loader30/30替代完成口径。
