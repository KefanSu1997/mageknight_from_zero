# 法术宝典的免费施法要限定到本次调用

不能依赖 ActionEffectId 的相邻枚举位置推导供给法术效果。使用原 JSON 身份及 ActionSystem 映射，先检查真实有色材料与同色供给、法术分支和额外费用，再支付弃牌材料。焚毁允许白昼及免印刷蓝/红/黑等魔力，不应成为后续普通法术的全局免费或白昼许可。

场景需要同时显示宝典和所选供给原卡，并检查供给未被领取。区分模块夹具与实际出牌：新增伤牌、弃材料、宝典进入已打出或永久移除分别计数，不能漏算伤牌后修改代码迎合错误预期。
