# 亡君之盾：分次格挡按实际攻击而非敌人区分

原 `Assets/GameData/cards/items_020.png`：普通格挡6或对两次不同攻击格挡4；焚毁冰火格挡8或对最多三次不同攻击冰火格挡4。原女巫015有火3和冰3两次攻击，必须能分别使用分次格挡。

旧 `CombatPowerPool` 使用 `HashSet<int>` 保存已格挡敌人，并残留“一敌一次攻击”的假设。正式 `CardCombatActions.Block` 在格挡女巫第一击后，第二击错误抛出“分次格挡必须选择尚未使用该效果的攻击”。首后台失败证据 `AutomationOutputs/RulesState/20260918_181630_9022ea94` 保留。

消费身份改为 `(Target, Attack)`；`AvailableBlocks` 和 `ConsumeBlocks` 的攻击序号缺省0保留旧单击调用，正式即时消费者与PVE预约消费者都传实际序号。每张盾每次仍只提供一份分次格挡；不能把两份同时叠在同一攻击，也不能复用已消耗攻击槽。战末/回合末沿用既有清理。

PVE复用原神器定义/卡面与真实手牌，显式选择普通/焚毁和单次/分次。已格挡的目标预览先显示“已格挡”，避免重选同敌以切换攻击序号时就调用消费资格查询、导致面板渲染异常。确认重复格挡仍明确拒绝，不消耗剩余资源。女巫两击与另一哨卫为三次合法攻击。
