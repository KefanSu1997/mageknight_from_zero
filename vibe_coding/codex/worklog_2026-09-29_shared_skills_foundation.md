# 2026-09-29 共享互动技能与正式行动边界

## 本批目标和范围
继续完整 Demo 初版，先让七项互动技能具备真实公共区及双玩家回合承载。本批完成后台承载及痛苦仪式、风雨平复、自然复仇的实际共享交易；其余四项已审原文和付款钩子，尚未实现。场景操作入口尚未接入，所以英雄合法场景入口仍为63/70，不能因后台类完成增加到66。

## 实现
- GameEngine持有单一SharedSkillArea，实际当前玩家与同一ActionContext校验；开始回合只收回有原文短期限的标记，轮末收回公共区。不会拿未学公共技能供应充当已学中央标记。
- PveJourneySession接收不同身份的实际伙伴，按原战术顺序切换真实Player和个人升级对象；共享高级牌/法术/神器供应排除每名玩家已经持有的唯一牌。
- 痛苦仪式选零至两张实际伤牌移除，领取时同一真实伤牌横置3并进入已打出区；风雨平复用最低1减费，实际移动支付，不通过override开放不可通行山湖。
- 自然复仇绑定敌人引用与攻击槽；1移动换1减攻，降为0计成功格挡。原授予效果保留整个回合，移动支付仅本场，真实回合末清除。中央到主人下次实际回合开始归还。
- 六项互动技能的原文字位于side1_skill.total_description，旧加载器只读空根字段导致Unspecified；现在仅已知互动原ID回退合作面文字，保留严格频率校验。旧generic SkillActions.Use不能再绕过公共区直接调用简化效果。

## 本批发现的实际旧错误
正式“移动→行动”边界应丢弃未用移动/影响点，保留灵动等整回合转换许可。原PveJourneySession普通入战及地下城未清旧池，导致既有六个灵动/外交夹具以错误时序通过。现修这两个行动起点，未将所有BeginBattle一刀切清池（地道附接、行动内迷宫生成的移动不能再次丢弃）。六用例仍用原数值、伤牌及后续消费者断言，仅把产生资源原牌改为战斗内battle.Play。新增场内原移动牌Choices仅在灵动/笨重消费者存在时开放，不借底层API绕过UI可用选择。
