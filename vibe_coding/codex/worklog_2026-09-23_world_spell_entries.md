# 原地道、飞翼与持续地点接入

## 实现思路

让原法术操作真实旅程地图，沿用 `TunnelTravelEffect`、`WindWingsEffect`、`CardTravelActions` 和 `FortifiedSiteActions`，不把独立遭遇伪装成地点。004/023接入统一出牌选择：已揭示相邻格逐步选路径、实际存活敌人选停攻目标。作用中的输入临时写入正式上下文，结束后恢复；原费用、地形合法性与递增移动费用仍由正式规则处理。

`PveJourneySession.World` 持续持有同一个 EnemyTokenSupply；地图地点持有供给中的实际守军。地道强化先校验真实地点/守军/供给，再交原效果付费与移动；随后只附接战斗控制器，不重复提交一次行动。战斗结束后按实际幸存者决定征服或撤退，复用原守军弃置/替换与声誉；法师塔从实际供应选奖励，正式回合末取得、补位和补牌。

场景配置增加法师塔、要塞，以及四个既有原怪物卡面/定义。新增路径、目标、奖励面板均展示原文字和原图；布局仍是自定示范地图，地点背景复用既有美术，不能称为完整原世界或完成独立地点美术。旅程菜单的遭遇行距做了小幅收紧，以避开手牌按钮；完整菜单视觉复核留待后续实际游玩。

## 实际场景证据

两组合法七原牌构筑，各自保持真实玩家、手牌、资源与回合，不重建战后快照：

1. 原戒指/护符供费 → 地道经过山脉进入法师塔 → 黑夜之翼停止毒巫师攻击 → 原火球实际击杀 → 征服/弃置守军 → 从真实供应选择复原 → 正式回合末取得入手、补位和清理临时魔力。63步93断言合并通过。
2. 两原戒指供费 → 基础地道穿山到沙漠、不扣移动 → 原行进强化实际支付绿晶产生4移动 → 清风之翼经山/湖/平原共4格逐格消费 → 同玩家兽人战斗承伤/原狂怒击杀 → 正式次回合原宁静治疗一张真实伤牌，另一张保留。67步99断言首次通过。
