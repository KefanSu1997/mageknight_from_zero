# 原神器资源与战斗外连续入口（2026-09-23）

## 改动目的与实现

将原四色戒指、金币包、宝石袋、皓日/黑暗护符和防护旌旗的实际操作接入连续 Demo。复用既有原定义、原图和 CardPlayActions，未复制神器效果，也未重写费用规则。新增 PveArtifactInputs 只负责输入分类、原效果允许的颜色数与范围；PveJourneySession.Artifacts 负责战斗外原牌及自有附旗目标校验；PveBattleSession 增加资源神器入口。

手牌界面提供正常/焚毁、每颗独立选色和实际部队选择。库存晶体、临时标记、无尽资源、昼夜许可分别显示，牌区沿用真实实例。新增金色标记转换入口，调用正式 ManaTokenActions.ConvertGold：后台首次失败揭示既有规则不会自动把金色支付为任意基本色，玩家必须能够实际选择并消费。保护旗焚毁的回合末清理选择也已接界面，尚未跑其场景，不算已验收。
