# 七英雄标准开局的来源核对

## 原规则及原素材

- 本地 `resources/rulebook/rulebook_chinese_quick_start.PDF` 第4页：每位英雄16张基本行动，其中两张为对应英雄的独特卡。
- 同书第5页：16张洗混，抽5；初始护甲2/手牌上限5、一个指挥标记。英雄卡下方三个魔晶标记仅供虚拟玩家使用，不是玩家初始资源。初始技能在未学技能堆中，不能直接全部装配。
- 本次只渲染并查看这两页，输出 `tmp/pdfs/hero_setup_4.png`、`hero_setup_5.png`。既有原中英文卡图/定义仍为运行时来源，未制作新卡。
- 牌名和替换对应交叉核对 [Starting Deck](https://unofficialmageknighttheboardgame.fandom.com/wiki/Starting_Deck)，再对应本地 `resources/images/cards/basic_card_en_4x7.jpg`、`Assets/GameData/CardsAssets`。使用含原扩展专属牌的七英雄版本；不是旧本体每人只有一张专属卡的版本。

## 既有素材来源异常

基本卡合图包含28种牌面，而上述七英雄标准起始牌库合并只有26种。`basic_card_011`（利斧投掷）、`basic_card_025`（战斗之怒）不属于这七位原英雄的标准牌库。网络来源将 Battle Rage 关联到民间英雄 Ymirgh：[BGG玩家记录](https://boardgamegeek.com/thread/3650755/ymirgh-in-blood-kin-of-the-dwarves-scenario)、[民间英雄介绍](https://ludopedia.com.br/topico/11944/ymirgh-novo-heroi-para-o-mage-knight-fan-made)。本地牌面亦为同一矮人角色。

因此这两张不进入本次七英雄原版开局；旧效果、手牌演练和历史验收记录保留，不删除失败或抹去历史。此前“121张原卡”属于仓库既有卡库有限验收口径，不能据此断言121张全为官方原版；目录来源分类仍需补明确标签。本次没有通过删除这两张去缩小既有实现任务，也没有将其配置给原英雄冒充原版。

正式世界尚未完整：当前英雄开局接自定地形和遭遇目录，标准传送门/原版板块探索、升级选技能/高级行动奖励仍待。不得把“标准16张牌开局”写成整局原版场景已完成。
