# 正式回合最小出牌/弃牌与无牌跳过

## 规则与修改

依据本地原规则书第6页（`tmp/pdfs/round_book_page_6.png`）：回合中至少打出或弃掉一张牌；手牌为空而牌库尚有牌时可以结束并补牌。开始前手牌与牌库均空时，未有人声明则声明轮次结束，已经进入倒数则跳过最后回合。回合前战术处理仍保留，不能靠空过刷新每回合技能、魔力或补牌。

`PlayerDeck` 记录当前回合成功出牌/弃牌次数，在正式开始回合时重置。横置、正常原卡、实际弃牌都走共用牌区操作；附旗不进入已打出区、神器焚毁直接永久移除，因此分别在成功原入口记录一次。取得新伤牌到弃牌堆、从供应取得牌、治疗移除伤牌不冒充弃牌。

`GameEngine.BeginEndCurrentTurn` 在任何资源清理前验证最少操作和实际非伤弃牌选择，重复选择和伪造同ID实例会拒绝。结束时所选牌先保持在手中，正式奖励完成后才在 `CompleteEndCurrentTurn` 弃掉并补牌。旅程共用这一流程；拒绝后保留活动回合、资源与次数，不能再次调用开始回合刷技能。

新增正式 `SkipEmptyTurn`，仅已声明结束、手牌牌库双空的玩家可用；只推进顺序和倒数，不调用 StartTurn。旅程首页显示无牌声明提示；倒数中的双空玩家显示跳过入口。便捷 `RunOneTurn` 改为真实合法休息，不能静默空过。

将这些夹具改为真实出牌/弃牌且保留既有实体、技能、费用、回合和轮次断言；新增7个最少操作专用用例。`20260923_053552_a4039126` 为19/21通过，两项剩余失败：积蓄力量在真实弃牌补牌后不再有第二张可蓄牌；换轮后断言误查弃牌区。分别把起始牌库从7增到8保留消费者，并核对新轮同一牌实际入手。`20260923_053836_614872de` 仅补这两个方法的3个参数用例，全通过。

有效范围合计124个通过。原失败报告保留。覆盖只用技能后结束拒绝且状态不变、前回合弃牌不串计数、非法弃牌选择无清理副作用、治疗空手后合法补牌、附旗/焚毁计数、倒数双空玩家跳过不刷新资源与次数。
